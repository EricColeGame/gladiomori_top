### 物理演算、コリジョン、ガードフレーム

『Gladio Mori』では、防御行動と攻撃モーションが密接に結びついています。プレイヤーの経験や初期デモテストによると、多くの斬撃や刺突モーションは本質的に方向性を持ったガードとしても機能します。適切な角度で刃を相手の攻撃に交差させれば、物理エンジンがクリーンヒットではなく「受け流し（ディフレクション）」や「バインド（刃の絡み合い）」として判定します。また、攻撃入力を長押しすると、キャラクターの硬直終了フレームがアクティブガード姿勢に固定され、防御態勢を保ちながら位置取りを変えることが可能です。

```
[攻撃始動] ---> [攻撃中 / 衝突判定フェーズ] ---> [フレーム維持ガード / 硬直終了]
```

当**gladiomori weapons list**から武器を選択する際は、以下の基本要素のバランスを考慮する必要があります：

*   **武器の長さとリーチ：** 長い武器は空間を制圧しますが、接近戦のインファイトでは不利になります。
*   **質量と衝撃力：** 重い武器はガードに対して崩しの運動量を生み出します。
*   **刃筋（エッジアライメント）と刺突特性：** 鋭い切っ先は隙間を貫通し、幅広の刃は切断・部位破壊に優れます。
*   **装備コスト（ポイント）：** 上位武器はキャラ作成時のポイントプールを多く消費するため、副装備が制限されます。

## 武器カテゴリー別詳細解説

理想のビルドを構築するには、単純な攻撃力だけでなく、実際の対人戦で各武器カテゴリーがどのように機能するかを理解する必要があります。

### 1. 刺突特化ブレード：レイピア＆エストック

レイピアは細身の刀身が特徴で、直線的な素早い踏み込み突きを得意とします。物理ダメージは切っ先の速度に大きく依存するため、前進してくる相手をカウンターの突きで捉えれば、一撃ノックアウトや致命的な胴体貫通を狙えます。

*   **長所：** 片手武器の中で圧倒的な前方リーチ、驚異的な復帰速度、卓越した切っ先のコントロール性。
*   **短所：** 鍔（ツバ）の内側に潜り込まれると無力化しやすい。重い薙ぎ払い攻撃に対する阻止力が低い。
*   **戦術的アドバイス：** 常に間合いを維持しましょう。上段への突きをフェイントにして相手の縦ガードを誘い、軸をずらしながら脇腹を狙い撃ちます。

### 2. 万能な斬突両用：アーミングソード＆バックソード

アーミングソードは、歴史的剣術における基本かつ理想的なバランスを備えています。均整の取れた重量配分により、水平斬り、下からのフォールスエッジ（裏刃）攻撃、不意の刺突を柔軟に繰り出せます。一方、片刃のバックソードは峰が厚く作られており、両刃の汎用性を犠牲にする代わりに強烈な叩き斬る威力を発揮します。

```
アーミングソードの戦術フロー：
[直線的な刺突] <---> [ショートエッジパリィ] <---> [振り下ろしのツォルンハウ]
```

### 3. 二刀流セットアップ：ダブルアーミングソード＆ダブルスレイヤー

ジッセのダブルアーミングソードやダブルスレイヤーといった二刀流ビルドは、ロードアウトポイントを大量に消費します（18ポイント以上になることも多々あります）。しかし、攻防を同時に行えるアングルを確保できるのが強みです。片方の刃で相手のガードを抑え込みつつ、もう片方の武器でがら空きの急所を切り裂くことができます。

コミュニティの報告によると、二刀流はカメラ操作とスタミナ管理が極めてシビアであり、攻撃のタイミングを誤ると両腕を伸ばしきった状態で無防備になってしまいます。

### 4. 装甲破壊兵器：ウォーハンマー＆ヘビーメイス

公式拡張やMODの歴史コレクションを通じて導入されたウォーハンマーは、頭頂部のスパイク、後部のピック（嘴状の爪）、重量のある打撃面を備えています。肉体を切り裂くのではなく、重厚な衝撃力で防御ブロックを崩し、相手をよろめかせてガード復帰を大きく乱します。

## 実戦戦闘テクニック：武器のポテンシャルを最大化する方法

**gladiomori weapons list**からどの武器を選んだとしても、剣術の普遍的な原則に従うことが勝利への近道となります。

```
戦闘時の判断ツリー：
[相手が大振りの攻撃を仕掛けてきた場合] 
   ├── 後退する（スカ振りを誘い、レイピアの突きで反撃）
   └── ガードの下をくぐり前進する（ウォーハンマーで間合いを詰める）
```

1. **間合い（メジャー）の支配：** 相手の最大攻撃射程の先端に立ち続けてはいけません。完全に届かない距離を保つか、あるいは斬撃の速度が乗らない懐の内側へ思い切って踏み込みましょう。
2. **硬直維持ガードフレームの活用：** 攻撃終了時、武器が上段や外側の構えで終わる場合は攻撃入力を長押ししたままにします。これにより武器が物理的な盾となり、相手の相打ちカウンターを弾き返すことができます。
3. **無装甲部位を狙う：** 敵のロードアウトをよく観察してください。相手が**gladiomori weapons list**の中でも高コストな武器を装備している場合、ポイント不足で脚部や首元の防具を削っている可能性が高いです。その露出した部位を集中的に狙いましょう。
4. **フェイントで角度を操る：** 上段からの振り下ろしを始動させ、急激にキャンセルするかカメラを振ることで、その運動量を切り上げ攻撃へと変化させます。物理エンジンは、こうした回転エネルギーを利用した変則的な攻撃に高い威力を与えます。

## よくある質問（FAQ）

### Gladio Moriの武器一覧の中で、初心者に最もおすすめの武器は何ですか？
**ソード＆シールド**の組み合わせ、または**シングルアーミングソード**が初心者には最適とされています。どちらも直感的な防御力を備え、ポイントコストも控えめで、フットワークや運動量の仕組みを学ぶ間も判定が寛容で扱いやすいためです。

### Gladio Moriのロードアウトポイントはどのように機能しますか？
武器、逆手の盾、兜、体防具など、すべての装備に固有のポイント値が設定されています。キャラクター作成時にプレイヤーには一定の上限ポイントが与えられます。二刀流セットのような強力な装備は最大18ポイントを消費するため、規定コスト内に収めるには防具を削る必要があります。

### 特定の武器を使って相手の武器を弾き飛ばす（ディスアーム）ことはできますか？
はい、可能です。フック、鍔（ヒルト）、ウォーハンマーのような重い打撃面を持つ武器は、相手の刃を物理的に絡め取ったりねじ伏せたりできます。また、相手の手首や前腕部に強い衝撃を与えることで、武器を完全に落とさせることが可能です。

### 公式のGladio Mori武器一覧には今後も武器が追加されますか？
はい。開発アップデートにより、長柄武器（ポールアーム）や特殊ダガー、新たなフェンシングソードなど、歴史的な武具が定期的に追加されています。またMODサポートにより、専用サーバーでコミュニティ独自の歴史的武器を作成・テストすることも可能です。
