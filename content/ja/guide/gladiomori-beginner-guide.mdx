## コアとなる戦闘物理システムの理解

『*Gladio Mori*』の基盤は、リアルな生体力学と武器の質量の上に成り立っています。キャラクターが攻撃モーションを繰り出しているからといって、それだけでダメージが発生するわけではありません。肉を裂き、骨を砕き、急所を貫くためには、武器の刃が十分な速度を伴って物理的に接触する必要があります。

すべての攻撃はスタミナゲージを消費し、キャラクターの回転慣性に大きく依存します。後退しながら大剣を振ると相対速度が大幅に低下し、相手の装甲をかすめる程度の当たり判定にしかなりません。逆に、踏み込みながら上半身を鋭く回転させれば運動エネルギーが増幅され、ただの水平薙ぎ払いであっても即死攻撃へと昇華します。

| 戦闘システム | 機能と仕組み | 戦術的重要度 |
| :--- | :--- | :--- |
| **刃筋の制御（Edge Alignment）** | 対象の表面に対する刃の角度と向き | 刃の側面による浅いヒットを防ぎ、最大の斬撃深度を確保する |
| **回転慣性（Rotational Momentum）** | スイングに上半身と足さばきの回転力を上乗せする | 衝突運動エネルギーを増加させ、通常攻撃を致命的な斬首へと変える |
| **解剖学的ヒットボックス** | 生体構造の急所（首、心臓、内臓など）に基づくダメージ判定 | 単純なHPの削り合いを回避し、一撃必殺のキルを可能にする |
| **物理演算パリング** | 刃と刃の直接的な衝突判定 | スクリプト化された入力ロックに頼らず、相手の運動エネルギーを受け流す |

これらの根本的なシステムを理解することで、立ち回りへのアプローチが劇的に変わります。ボタンをがむしゃらに連打するのではなく、タイミング、間合い、侵入角度が勝敗を握る極限のデュエルとして、一戦一戦を捉えなければなりません。

## カスタムアニメーションとモーション作成の基本

『*Gladio Mori*』の最大の特徴の一つがアニメーションエディターです。プレイヤーは独自の攻撃モーションを構築、編集、微調整できます。コミュニティが作成したモーションセットをダウンロードするのも手ですが、エディターがフレーム数、速度、硬直のバランスをどのように取っているかを理解しておかなければ、実戦で通用しない隙だらけの技をランク戦に持ち込むことになってしまいます。

すべてのカスタムモーションは、始動（予備動作）、実行（攻撃判定）、硬直（リカバリー）という3つの明確なフェーズで構成されています。始動を速くしすぎると攻撃の運動エネルギーがシステム側で減衰され、逆にリカバリーの体勢をおろそかにすると、相手の反撃の突きに対して完全に無防備となってしまいます。

| アニメーションのフェーズ | 重要なポイント | 初心者が陥りがちなミス | 理想的な設定 |
| :--- | :--- | :--- | :--- |
| **フェーズ1：始動（Wind-Up）** | 慣性を蓄積し、重心を移行させる | 0.5秒以上かかる大振りで読まれやすい予備動作 | 上半身をコンパクトに溜め、前足で一歩踏み込む |
| **フェーズ2：実行（Execution）** | 刃の速度と腰の鋭い前方への推進力 | 攻撃ラインを越えて身体が回りすぎてしまう | 標的の中心線を水平かつ鋭く切り抜ける |
| **フェーズ3：硬直（Recovery）** | 武器を防御姿勢（ガード）へと戻す | ヒット判定後も手足が伸びきったままになる | 肘を素早く引き締め、即座に上段または下段ガードへ移行する |

最初のオリジナルモーションを作成する際は、「無駄のない動き」を徹底してください。練習モードでは派手でアクロバティックな回転技が見栄えよく映りますが、プレイヤーの経験上、大会を制するのは常に規律ある直線的な刺突や、短い軌道から放たれる素早いスナップ攻撃です。

```
カスタムモーション作成の手順：
1. モーションエディターを開き、空の基本構えを選択する。
2. キーフレーム1を設定：後ろ足にわずかに体重を移し、刃を肩の高さまで引き絞る。
3. キーフレーム2を設定：肩を回転させながら、腰を前方へ0.25メートル押し出す。
4. キーフレーム3を設定：相手の喉元の高さに合わせて刃を水平に揃える。
5. キーフレーム4を設定：8フレーム以内に両腕を引き、オックス（上段）またはルーフガードへ戻す。
6. ラグドール標的に対してテストを行い、斬撃速度と姿勢の安定性を確認する。
```

## 防御の極意：フットワーク、間合い、パリング

華々しい攻撃に目を奪われがちですが、連戦を生き残る鍵となるのは完璧な防御です。『*Gladio Mori*』では、ガードを固めて引きこもる戦術は有効な解決策になり得ません。重い一撃を受けると体勢を崩されたり、武器を弾き飛ばされたりするためです。真の防御とは、間合い（格闘ゲームにおける「スペーシング」や「差し合い」）を完全に支配することにあります。

以下の防御テクニックを習得することで、アリーナでの開幕死を劇的に減らすことができます：

*   **スリッピング・ザ・ジャブ（Slipping the Jab）：** 相手が直線的な刺突を放ってきた際、わずかに斜め前へと軸をずらして踏み込み、がら空きになった相手の首元を即座に狙える角度を確保する。
*   **アクティブ・ディフレクション（Active Deflection）：** 受動的に攻撃を待つのではなく、相手の武器の軌道に向けて自身の鍔（つば）や刀身の基部（柄に近い頑丈な部分）をぶつけるように打ち込んで軌道を逸らす。
*   **ゾーン・リトリート（Zone Retreat）：** 一瞬だけ構えを解いてダッシュ姿勢に入り、上半身を相手の切っ先が届く限界のわずか外側へと引き、空振りした相手の硬直に合わせて踏み込み直す。
*   **チャンバー・パリー（Chamber Parries）：** 相手の攻撃と全く同じ軌道を描く攻撃をタイミングよく繰り出し、空中で相手の刃を噛み合わせながら弾き、自身の刃をそのまま押し込んで斬り裂く。

武器での直接ブロックではなく「距離」で攻撃を回避すれば、貴重なスタミナの消費を最小限に抑えられます。空振りを重ねて息切れした相手に対しては、計算された一撃のリポスト（反撃）を叩き込むだけで勝負は決します。

## よくある質問（FAQ）

### 攻撃が相手に当たっても浅いヒット（glance）になり、致命傷を与えられないのはなぜですか？
浅いヒットになる主な原因は、インパクト時の武器速度が不足しているか、刃筋がズレていることです。上半身のひねりを攻撃に乗せているかを確認し、刃の腹や鍔付近ではなく、刀身のスイートスポット（切っ先から3分の1あたり）で捉えるように振ってください。

### 試合開始の数秒で一撃死するのを防ぐにはどうすればよいですか？
開幕の激突で相手に向かって真っ直ぐ直進してはいけません。早期の死亡の多くは、長く突き出された槍やロングソードの先端に自ら飛び込んでしまうことで発生します。わずかに斜めの角度からアプローチし、相手の武器リーチの出入りを繰り返して初手を空振りさせ、硬直フレームを狙って踏み込みましょう。

### この gladiomori 初心者ガイドの知識だけで、デフォルトのモーションセットでも勝てますか？
十分に勝てます。デフォルトのモーションセットは、堅実なリカバリーフレーム、癖のないニュートラル姿勢、安全なヒットボックスでバランス良く設計されています。カスタムモーションは個性的な動きや初見殺しの角度を生み出せますが、デフォルト技を用いた強固な立ち回り、間合い管理、的確なタイミングがあれば、最適化不足なカスタム技を使う相手を容易に圧倒できます。

### 『Gladio Mori』ではスタミナが武器ダメージにどのように影響しますか？
スタミナが赤色の危険域に落ち込むと、キャラクターのスイング速度と姿勢の安定性が著しく低下します。衝突時の運動ダメージは刃の速度に直結しているため、スタミナ不足の状態では攻撃が鈍重になり、相手の身体に当たっても威力を失って弾かれるか、装甲を貫通できなくなります。
