## 戦闘のコアメカニクス：ダメージと物理演算の仕組み

固定のフレームデータや事前に用意された被弾モーションに頼る一般的な格闘ゲームとは異なり、本作の戦闘は完全に物理シミュレーションによって計算されています。武器の運動量、質量、ヒット時の進入角度、そして速度によって、攻撃が鎧に弾かれるか、それとも肉を両断するかが決定されます。

攻撃がヒットすると、キャラクターの回転トルクと前進運動量に基づいて運動エネルギーが算出されます。その場から動かずに繰り出す突きは最小限のダメージしか与えられませんが、全身の体重を乗せたランジ（踏み込み突き）は致命的な深度まで貫通します。プレイヤーコミュニティの報告や競技プレイヤーの検証によると、急所への浅いかすり傷であっても急速な失血死を引き起こし、相手のスタミナと移動速度を激減させて優位に立てることが明らかになっています。

### ダメージ部位と致死性マトリクス

攻撃効率を最大化するには、即死や致命的な大出血をもたらす解剖学的な弱点を的確に狙う必要があります。

| 身体部位 | 主要ターゲットポイント | 要求アーマー貫通力 | 戦闘結果 | 戦術的優先度 |
| :--- | :--- | :--- | :--- | :--- |
| **頭部 / 頚部** | こめかみ、喉、頸椎 | 低〜中 | 即死 / 首の切断 | 最優先（第一目標） |
| **胸部 / 体幹** | 心臓、肺、みぞおち | 中〜高 | 重度の出血、行動不能 | 高（突き攻撃を集中） |
| **上肢** | 肩、前腕、手 | 低 | 武器の落下、武装解除 | 状況次第（防御的パリィ時） |
| **下肢** | 大腿動脈、膝 | 中 | 移動不能、這い状態 | 中（間合いの制圧） |

これらの解剖学的ヒットボックスを把握することで、状況に応じた構えを選択できるようになります。例えば、相手が胸元を固くガードしている場合、膝を狙った下段払いを繰り出せば相手の武器を押し下げさせることができ、がら空きになった頭部へ追撃を叩き込む隙が生まれます。

### 武器の詳細解説

#### ロングソード：基準となる王道武器
両手持ちのロングソードは、最もバランスの取れた性能を備えています。十字の鍔（クロスコート）は卓越した防御範囲を誇り、両刃構造によってスイングの途中で軌道を変化させるトリッキーな攻撃が可能です。本 **gladiomori ガイド** で間合い管理の基本を学ぶにあたり、まさに基準となる一本です。

#### レイピア：外科手術のごとき精密さ
レイピアは水平方向の斬撃能力を犠牲にする代わりに、比類なき突進速度を獲得しています。手足を切断することはできませんが、剣先の移動速度はゲーム内最速を誇ります。相手がスイングの弧を描ききる前に眼窩や喉を正確に貫くことで、瞬時に敵を仕留めることが可能です。

#### グレートソード / ツヴァイヘンダー：慣性の支配者
重量級の武器を扱うには、その重さ（慣性）を完全にコントロールしなければなりません。グレートソードで水平斬りを空振りした場合、大きな硬直モーションによって無防備な状態を晒すことになります。しかし、ハーフソーディング（刀身を握る技法）の維持や慣性を乗せた連続攻撃はあらゆるガードを粉砕し、相手の手から小振りの武器を文字通り弾き飛ばす力を持っています。

## カスタム技エディター：必殺の技を構築する

本作の最大の特徴の一つが、独自の攻撃、パリィ、フットワークのシーケンスをプレイヤー自身が設計できる独自のアニメーションクリエーターです。実戦で通用する技セットを作成するには、予備動作（タメ）、運動エネルギーの生成、硬直、そして体勢バランスの調和が不可欠です。

見た目が派手な技であっても、重心が前に崩れすぎていると返り討ちに遭う原因となります。エディターで技をデザインする際は、コンパクトな構え（チェンバー）と、素早くニュートラルガードへ復帰するフェーズを最優先に設計してください。

### エディター内における攻撃フェーズのバランス調整

| アニメーション段階 | 物理的・機構的役割 | 理想的なフレーム / 時間 | 避けるべき典型的なミス |
| :--- | :--- | :--- | :--- |
| **構え / 予備動作（Chamber）** | 運動量を蓄積し角度を設定 | 150ms ～ 250ms | 背中側まで大きく振りかぶりすぎる |
| **リリース / 加速（Release）** | 武器先端が前方へ急加速 | 80ms ～ 140ms | 接触ポイントの直前で減速してしまう |
| **インパクト判定（Impact）** | 攻撃判定（ヒットボックス）が接触 | 50ms ～ 100ms | フォロースルーのない静止した刃角 |
| **硬直 / 復帰（Recovery）** | ニュートラルガードへ武器を戻す | 200ms未満 | インパクト後に身体の回転が硬直する |

```
[構え: 重心を後方へ] -> [腰の回転: トルクを前方へ] -> [リリース: 切っ先を走らせる] -> [ガードへの素早い復帰]
```

### 作成しておくべき必須カスタム技

1. **ディスエンゲージ・スラスト（後退突き）**：回避性のバックステップと同時に伸びやかな突きを繰り出す技。相手が前進してきた際、自らの被弾判定を下げつつ、相手の突入軌道上に刃先を置き去りにします。
2. **ハイ・トゥ・ロー・フェイント（上段から下段への変化技）**：頭部への唐竹割りから始動し、回転入力によって瞬時に軌道を変え、無防備になった前腕を斜め下から斬り上げる技。
3. **バインド・アンド・ショーブ（鍔迫り合いからの押し込み）**：至近距離で相手の鍔をロックするパリィ動作から、間髪入れずに逆の手で体当たり（バッシュ）を仕掛けて体勢を崩す技。

実戦テストの結果からも、ランクマッチでは複雑に回転する大技よりも、シンプルで無駄のないコンパクトなカスタム技の方が一貫して高い勝率を収めています。

## ステップ・バイ・ステップ戦術的ゲームプレイ戦略

ハイレベルな試合を生き残るには、立ち回り（ニュートラルゲーム）における緻密な駆け引きが求められます。様々な形状のアリーナで安定して勝利を掴むための、実践的な戦闘フローを紹介します：

### 戦術的エンゲージメント・プロトコル

| フェーズ | 主な目的 | 重要なアクション | リスク評価 |
| :--- | :--- | :--- | :--- |
| **フェーズ1：間合いの測定** | 射程を測り空振りを誘う | 攻撃射程の境界線を出入りする微細なステップ | 低（防御バッファを維持） |
| **フェーズ2：ガードの崩し** | 相手に大きな隙を強いる | 上段フェイントや刃先を当ててパリィを誘発 | 中（素早い突きによる迎撃に注意） |
| **フェーズ3：運動エネルギーの解放** | 最大威力の必殺打を叩き込む | 身体の回転とともに踏み込んで攻撃 | 高（攻撃モーションへの完全コミット） |
| **フェーズ4：体勢リセットまたは追撃** | 撃破確認または安全確保 | 即時のバックダッシュや旋回移動 | 中（相手の相打ちスイングを警戒） |

### ステップ1：距離感を確立する（立ち回り）
開幕と同時に闘技場の中央へ突進してはなりません。滑らかに円を描くように動き、相手の届くか届かないかの間合いに一瞬だけ足を踏み入れては下がり、反応を試します。焦った相手は早めに武器を振ってしまい、大きな硬直を晒すことになります。

### ステップ2：正中線（センターライン）を支配する
中世剣術の理論において、両者の間を結ぶ正中線を制する者が勝負を制します。常に剣先を敵の顔面に向けて構えてください。正中線をあらかじめ塞いでおくことで、相手の攻撃は自らのガードの外側を迂回せざるを得なくなり、こちら側は常に最短・最速の直線軌道で反撃を先回りさせることができます。

### ステップ3：運動エネルギーの受け流しを活用する
互いの刃が交差した際、決して真っ直ぐ後ろへ引いてはいけません。相手の刃に沿わせるように滑らせる（ワインディング）ことで、敵の切っ先を自分の体から逸らしつつ、こちらの刃を相手の手元や鎖骨へと滑り込ませます。

## 高度なアリーナサバイバル：フットワーク、空間制御、地形ギミック

足さばき（フットワーク）は、手に持つ刃と同じくらい強力な武器です。適切な下半身の安定がなければ、どれほど鋭利な名剣も効果を発揮しません。また、足場の凹凸、壁との衝突、障害物の存在は、武器の軌道に直接影響を及ぼします。

背後に石柱や壁がある状態で大振りの斬撃を繰り出すと、武器が壁に当たって跳ね返り、即座に大きな隙を晒してしまいます。逆に、相手を障害物に追い詰めることができれば、相手のカスタム技の軌道を大きく制限し、単調な突き攻撃しか出せない状況へ追い込むことが可能です。

### アリーナ地形の影響マトリクス

| アリーナ地形要素 | 戦術的メリット | 潜在的危険性 | 最適な武器選択 |
| :--- | :--- | :--- | :--- |
| **開けた砂地アリーナ** | 移動の自由度が最大、自在な旋回 | 側面への回り込みやフェイントに弱い | ツヴァイヘンダー / ロングソード |
| **柱の多いコロシアム** | 射線を遮断、1対1の状況を孤立化 | 石壁に武器が弾かれるリスク | レイピア / ショートソード |
| **高台・段差** | 高所からの攻撃に重力加速度ボーナス | リングアウトや落下スタンへの脆弱性 | ハルバード / スピア |
| **狭い通路** | 相手の横移動・回避を制限 | 直線的な突きを回避するスペースがない | ダガー / アーミングソード |

空間認識能力を磨くことで、自分が有利な場所へ戦闘環境を誘導できるようになります。重量武器の使い手は壁が密集した狭路へ誘い込んでスイングを壁にぶつけさせ、ダガーの使い手は広い広場へ引きずり出してリーチの差で安全に圧倒しましょう。本 **gladiomori ガイド** の戦術原則を適用することで、いかなる闘技場であっても勝率を飛躍的に高めることができます。

## よくある質問（FAQ）

### 『Gladio Mori』で突き攻撃が当たらないのを防ぐには？
突きの精度は、キャラクターの軸合わせと運動量に強く依存します。リリースのモーションが終わるまで、照準（クロスヘア）を相手の胸や頭に完全に固定し続けてください。また、踏み込み中に視点を急激に動かすと、物理トルクによって切っ先がブレてしまい、命中精度とインパクト威力の両方が低下するため注意が必要です。

### 作成したカスタムアニメーションはプレイヤー間で共有できますか？
はい。コミュニティ内ではカスタム技のコードやエクスポートされたアニメーションファイルが活発に共有されています。他のプレイヤーが作成した技を自分の技ライブラリへ直接インポートし、練習用ダミーでテストした上で、自身の反応速度や好みの武器に合わせてタイミングを微調整することが可能です。

### この gladiomori ガイドが初心者に推奨する最強の武器は何ですか？
初心者には標準の「ロングソード」を一貫して推奨します。防御時の刀身面積、扱いやすいリーチ、ミス時の復帰速度のバランスが最も優れているためです。重い長柄武器のような致命的な硬直リスクを負うことなく、斬撃、突き、バインドといった戦闘の基礎をしっかりと学ぶことができます。

### 相手に刃先が触れているのにダメージが入らないことがあるのはなぜですか？
本作のダメージは当たり判定の接触フラグではなく、物理演算によって算出されているためです。十分な運動エネルギーや速度が乗っていない状態で刃が触れても、肉を切り裂くことができず滑るか弾かれてしまいます。スイングの終わり際のかすり傷や、窮屈な至近距離で勢いのついていない攻撃は、皮膚を裂いたり鎧を突破したりするのに必要な威力を満たしていません。
