## 根幹となる戦闘システム：部位切断と臓器損傷

一般的な対戦格闘ゲームは、体力ゲージやスタミナゲージによって試合の展開を管理します。しかし『Gladio Mori』はその常識を完全に覆し、極めて緻密な物理演算ダメージモデルを採用しています。すべての武器の衝突はリアルタイムで判定され、刃の速度、ヒット角度、衝撃力、そして皮膚の下にある正確な解剖学的構造を計算します。

防具は視覚的に覆われている表面積でのみ攻撃を防ぐため、プレートアーマーの隙間、露出した喉、保護されていない関節などはすべて致命的な弱点となります。外傷が身体機能にどう影響するかを把握することは、戦闘の基本を習得するうえで極めて重要です。

### 解剖学的ダメージの優先度

長引く戦いを生き抜くには、激突の瞬間に剣闘士の肉体内部で何が起きているのかを把握する必要があります。

| 解剖学的部位 | 戦闘への直接的影響 | 戦術的影響 | 長期的な脅威度 |
| :--- | :--- | :--- | :--- |
| **重要臓器（心臓、脳）** | 貫通時に即死 | ラウンドが即座に終了 | 致命的（即死） |
| **主要動脈** | 大量出血 | スタミナ消耗、意識喪失、死亡 | 高（失血死） |
| **骨格系（打撃）** | 骨折、よろめき、破断 | ガード崩れ、バランス喪失、四肢機能不全 | 高（構造的破壊） |
| **筋肉組織** | 裂傷による運動出力の低下 | 攻撃速度と武器の威力が低下 | 中（攻撃性能の低下） |
| **四肢（手足）** | 完全切断 | 武器の喪失、または移動能力の完全喪失 | 致命的（戦闘不能） |

利き腕の手を失えば、出血死を免れたとしても、逆の手で戦うか素手での殴り合いを余儀なくされます。大腿四頭筋やハムストリングスに深い斬撃を受ければフットワークが崩れ、機敏な回避はほぼ不可能になります。

## 初心者向けスタートガイド：武器、防具、ロードアウト戦略

4人対戦アリーナに挑んだりキャンペーンを進めたりする前に、自身の戦術コンセプトに合ったロードアウトを構築する必要があります。本作には34種類のユニークな武器、3種類の歴史的シールド、そして17種類に及ぶモジュール式防具パーツが用意されています。

武器や各種機能の全容は、コミュニティのパッチノートやMod配信情報が確認できる[Gladio Mori Steamストアページ](https://store.steampowered.com/app/2689120/Gladio_Mori/)で直接確認できます。

### 武器クラスの基本系統

武器の選択によって、間合いの測り方やニュートラル時の立ち回りが大きく変化します。

| 武器カテゴリー | 代表的な武器 | 主なダメージ要因 | 最適な戦闘間合い |
| :--- | :--- | :--- | :--- |
| **片手刃物** | グラディウス、アーミングソード | 刺突（臓器） / 斬撃（動脈） | 近〜中距離 |
| **長柄武器・槍** | ハルバード、関刀、スピア | 刺突（急所） / 刃による引っ掛け | 遠距離・間合い管理 |
| **大型打撃武器** | 金棒、ウォーピッケル | 破砕 / 骨折 | 中距離からの確定反撃 |
| **両手・副兵装** | バックラー、タワーシールド、ダガー | 偏向防御、パリィ、距離詰め | 至近距離 |
| **素手** | 拳、掴み | 鈍的外傷、武装解除、足払い | 密着組み打ち |

フルスチールのキュイラス、可動式ガントレット、グリーブといった高位防具を装備すれば、刃物の脅威を大幅に軽減できます。ただし、重量は慣性と硬直時間に影響を与えます。コミュニティの検証では、頭部への刺突を警戒できる防御技術があるならば、オープンフェイスの兜と部分的なプレートアーマーの組み合わせが最も機動性のバランスに優れているとされています。

## 実践手順：カスタムモーションエディターの攻略

この剣闘士シミュレーター最大の目玉は、独自のアニメーションをゼロから作成できる自由度の高さです。プレイヤーを決まったコンボに縛り付けるのではなく、フレーム単位でポーズを調整できます。**Gladio Moriの遊び方**を解説するうえで最も重要な鉄則は「派手な見た目よりも、運動力学的バランスと隙の少ないリカバリーを最優先すること」です。

```
キーポーズ A（構え・溜め） 
       ↓ 
キーポーズ B（トルクと腰の回転） 
       ↓ 
キーポーズ C（インパクト・最大打点） 
       ↓ 
キーポーズ D（フォロースルー・運動エネルギーの逃がし） 
       ↓ 
キーポーズ E（ニュートラルガードへの復帰）
```

### 実戦で機能する攻撃を作成する必須手順

1. **基本スタンスの確立**：まずは両足を肩幅に広げ、安定した重心を確保します。溜め動作の段階で体重を前に乗せすぎると、足払いや転倒に対して非常に脆弱になります。
2. **初期の溜め（チャンバー）の設定**：胴体を捻り、武器を引き戻します。空気抵抗を最小限にしつつ、刃筋が振りの軌道と一致していることを確認してください。
3. **インパクトフレームの定義**：腰と肩の回転を利用して腕を一気に前に振り出し、運動エネルギーを発生させます。ゲームはこの瞬間における武器の移動速度を測定し、貫通力を算出します。
4. **フォロースルーのプログラミング**：関節に無理な負荷をかけることなく、目標地点を振り抜く勢いを自然に逃がします。
5. **リカバリー（後隙）の最適化**：安定したニュートラルガードへと素早く移行させます。この復帰モーションが長すぎると、素早い相手に隙を突かれて急所を刺し貫かれます。

| 設定項目 | 初心者向け推奨設定 | 避けるべき典型的なミス |
| :--- | :--- | :--- |
| **溜め時間** | 0.25秒 ～ 0.40秒 | 予備動作が長すぎて無防備を晒す |
| **刃筋のアライメント** | 振り軌道に対してズレ0° | 刀身の側面で叩いてしまう（切断深度がゼロになる） |
| **スタンス幅** | 肩幅の約1.2倍 | 足が交差してしまい、インパクト時に転倒する |
| **リカバリー時間** | 0.35秒未満 | 復帰が遅すぎて緊急ガードが間に合わない |

ゼロからの攻撃作成が難しく感じる場合は、統合されたModギャラリーを活用しましょう。コミュニティでは歴史的な武術モーション（HEMA着想の型、剣闘士スタイル、長柄武器の技など）が定期的に投稿されており、自身のロードアウトへ直接インポートできます。

## 初心者向け戦闘ガイド：アリーナで生き残る必須戦術

熟練のプレイヤーや高難度キャンペーンAIと相対するには、研ぎ澄まされた状況判断能力が求められます。**Gladio Moriの遊び方**を身につけるには、我慢強いディフェンスと、一撃必殺のオフェンスのバランスが不可欠です。

### 1. 刃筋（エッジアライメント）を狂わせない
斬撃武器で致命傷を与えるには、研ぎ澄まされた刃の角度に沿って正確にヒットさせる必要があります。浅い角度や斜めから当たると、武器は敵の皮膚や防具を滑るだけになり、運動エネルギーがほとんど伝わりません。相手のシルエットに対して刃が直角に食い込むよう意識して振り抜きましょう。

### 2. 防具の隙間を狙い撃つ
軽量な斬撃武器で鋼鉄の胸甲を叩いても無駄です。内もも、無防備な脇の下、露出した首、兜の覗き穴などを狙いましょう。ガントレットの隙間を抜いてグラディウスで手首の内側を突けば、橈骨動脈を断ち切り、数秒で相手を失血死に追い込めます。

### 3. 慣性と武器同士の衝突判定を利用する
武器にはモーション全体を通じて物理的な当たり判定が存在するため、ポジショニングによって相手の攻撃が最高速度に達する前に出鼻を挫くことができます。相手の振りかぶりに合わせて前へ踏み込めば間合いを潰し、攻撃を肩で安全に弾きながらカウンターの刺突を叩き込むことが可能です。

操作技術をマスターするには、ソロ練習からハイレベルなマルチプレイヤーへの明確なステップアップが必要です。以下の各モードを活用して、戦術を着実にテスト・洗練させていきましょう。

| フェーズ | コンテンツ | 主な目的 |
| :--- | :--- | :--- |
| **フェーズ1：チュートリアル＆ソロ** | オフラインAI戦 | 通信ラグのない環境で、人体ダメージ、間合い、武器のリーチ感を体得する。 |
| **フェーズ2：スキン・外観カスタマイズ** | 内蔵スキンエディター / 2D UVテンプレート | 独自の防具パターンや紋章を剣闘士に直接描くか、mod.io経由でインポートする。 |

コミュニティの秀逸な技を導入するにせよ、自力でミリ単位のポーズ調整に何時間も費やすにせよ、安定した強さを手に入れる鍵は冷静さにあります。武器の物理法則を尊重し、急所を守り、的確な一撃を叩き込んでアリーナの覇者となりましょう。

## よくある質問（FAQ）

### Gladio Moriの遊び方を学ぶ際、最初に意識すべきことは何ですか？
高度なカスタム技に挑戦する前に、間合いの把握、武器の有効リーチ、そして刃筋の正確さを意識してください。まずはソロキャンペーンで、動脈切断、骨折、臓器損傷といった異なるダメージが戦局にどう影響するかを観察しましょう。バランスの取れたデフォルトの技を使いこなすことで、安定した防御の基本が身につきます。

### 相手の手足を切断しなくても勝てますか？
はい。四肢の切断は勝利への手段の一つに過ぎません。脳や心臓といった急所を的確に一突きするだけで即座に決着がつきます。また、打撃武器で骨を砕いてノックアウトを奪うこともできますし、主要動脈に深い傷を負わせれば、手足がついたままでも失血死させることが可能です。

### 対戦で勝つためには自分で技を作成する必要がありますか？
いいえ、その必要はありません。アニメーションエディターは本作の大きな魅力ですが、すべての武器には実用的なデフォルト技が用意されています。また、ゲーム内のModギャラリーやmod.ioから他のプレイヤーが作成した高水準な技を直接ダウンロードして、そのままマルチプレイで使用することもできます。

### Gladio Moriは全プラットフォーム間のクロスプレイに対応していますか？
はい。Steam（PC）、PlayStation 5、Xbox Series X|S間での完全なクロスプラットフォームマルチプレイに対応しており、最大4人でのオンライン対戦が可能です。
