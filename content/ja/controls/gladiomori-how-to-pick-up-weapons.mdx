### 武器を拾うためのステップ・バイ・ステップ手順

決闘中に地面の武器を確実に拾うには、厳密なポジショニングが必要です。

1. **安全な距離の確保：** 敵が攻撃の構えに入っている間は、絶対に地面を見下ろしてはいけません。ダッシュするか間合いを取り、少なくとも武器2本分以上の距離を空けてください。
2. **重心を下げる：** しゃがみ姿勢を取り、剣闘士の手のひらと武器の柄との物理的な距離を縮めます。
3. **レティクルと上体の位置合わせ：** 刃先ではなく、メインの腕が武器の柄の真上に伸びるよう、上体の向きを調整します。
4. **インタラクトを実行：** ラグドール物理によって指が柄にしっかりと巻き付くまで、インタラクトキーを長押しします。
5. **ガード姿勢の復帰：** しゃがみを解除し、即座に武器を構えて防御態勢に戻ります。

## 武器のグリップ物理と武装解除（ディスアーム）

『Gladio Mori』では、単なるランダムなステータス異常によって武器を落とすわけではありません。武装解除はトルク、速度、局所的な部位ダメージによって引き起こされます。敵の攻撃が前腕に直撃したり、圧倒的なテコの力で刀身を絡め取られたりすると、剣闘士の握力が失われて武器を取り落としてしまいます。

| 武装解除の発生要因 | 物理的な原因 | 回復までの隙 | 危険度 |
| :--- | :--- | :--- | :--- |
| **前腕部への斬撃** | 筋肉の損傷により握力が一時的にゼロになる | 1.5 ～ 3.0秒 | 極大 |
| **重い刃の衝突（鍔迫り合い）** | 強烈な運動衝撃がグリップ保持の限界値を超える | 即時 | 高 |
| **柄頭・盾による打撃** | よろめきによって物理的に手が開かされる | 0.8 ～ 1.2秒 | 中 |
| **任意ドロップ / 投擲** | 戦術的に意図して装備を投げ捨てる・手放す | 制御可能 | 低 |

**武器の拾い方**を調べる際、腕へのダメージが重い武器の保持力に影響を与えるという点を見落としがちです。右腕に重度の裂傷を負っている場合、ツーハンド・グレートソードやバルディッシュを持ち上げることが困難になるため、グラディウスやダガーなどの軽い予備武器を拾う方がはるかに安全な選択となります。

## 実戦での戦術的移動：敵の猛攻を受けながら武器を回収する

敵が突進してくる中で装備を拾うには、正確なフットワークが求められます。落ちた剣に向かって無防備にダッシュすれば、熟練のプレイヤーなら武器を拾うモーションの隙を見逃さず、確実に振り下ろし攻撃を叩き込んできます。

### ベイト・アンド・スライディング（囮スライディング）

- **速度を乗せて接近：** 武器のある場所へ向かってスプリントし、敵に前のめりな追撃を誘発させます。
- **スライディング入力：** 武器の真上を通過するように、しゃがみスライディングを発動します。
- **慣性移動中にインタラクト長押し：** 自キャラが柄の上を滑り抜ける瞬間に、拾うボタンを入力・保持します。
- **ローリングで離脱：** スライディングの終わりを方向キー＋回避ローリングでキャンセルします。敵の攻撃の軌道下をすり抜けつつ、武器を装備した状態でローリングを終えることができます。

```
[敵の突進・大振り] --------> \ （頭上を空振り）
                              \
[プレイヤースプリント] ---> [武器上をスライディング＋拾う長押し] ---> [敵の背後へローリング離脱]
```

### 地形や障害物への注意点

闘技場の壁、転がる死体、バリケードなどに接触している武器は、ラグドール物理エンジンに引っかかってしまうことがあります。槍の先端が倒れた敵の胴体にめり込んでいる場合、無理にインタラクトしようとするとキャラクターがつまずく原因になります。このような状況では、障害物との当たり判定が重なっていない安全な位置まで、柄の周りを回り込んでから回収してください。

## トラブルシューティングと物理エンジンの挙動対策

白熱した対戦中、物理エンジンの予期せぬ挙動によってアイテムがうまく拾えない場合があります。代表的な不具合の原因と対処法は以下の通りです。

| 症状 / 問題 | 根本的な原因 | 効果的な解決策 |
| :--- | :--- | :--- |
| **手が柄をすり抜けてしまう** | 高レイテンシや通信の同期ズレ | インタラクトを押す前に一瞬（0.5秒）静止する |
| **触れた瞬間に武器が吹き飛ぶ** | 地形メッシュとの物理コリジョン重複 | 一度距離を取り、反対側の角度から近づき直す |
| **柄ではなく刃先を掴んでしまう** | レティクルの照準位置のズレ | 鍔（ツバ）やグリップ部分をピンポイントで見つめる |
| **手を握ろうとしない** | 直前の攻撃で腕の部位が完全に破壊されている | 拾う手を切り替えるか、軽量な片手武器を狙う |

**武器の拾い方**をマスターする上では、焦ってボタンを連打するよりも、冷静な間合い管理と丁寧な微調整を行うことが何よりの近道です。

## よくある質問（FAQ）

### 『Gladio Mori』の体験版（デモ版）で武器が拾えないのはなぜですか？
初期の体験版やプレイテスト環境では、特定の武器ラックやマップ上に落ちている武器の一部が、インタラクト可能なオブジェクトではなく静的な背景プロップ（装飾）として配置されている場合があります。プレイヤーコミュニティの報告によると、武器の持ち替えや動的な回収システムの挙動は、開発チームが配信する特定のゲームモードやバージョンによって異なる場合があります。

### PC版で武器を拾う正確な操作コマンドは何ですか？
デフォルト設定の場合、落ちている武器に近づき、`Ctrl` または `C` でしゃがんで目線を地面に合わせ、柄を直接視界に捉えながらインタラクトキー（`E` または `F`）を長押しします。その際、武器の柄を掴めるよう、対応する手が素手（空き状態）になっていることを確認してください。

### 武器を投げてから再び拾うことはできますか？
はい、可能です。戦術的な武器の投擲は、敵の大きな攻撃モーションを中断させたり、ガードを崩したりする非常に有効な手段です。投げた武器が地面に突き刺さるか防具に当たって跳ね返った後、ダッシュで接近してスライディング等で回収動作を行えば、素早く再装備できます。

### 腕にダメージを受けると両手持ち武器が拾えなくなりますか？
はい。どちらかの腕に深刻な筋肉損傷や骨折を負った場合、剣闘士は重量のある両手持ち武器を適切に扱うことができなくなります。そうした状況に陥った際は、無事な方の片手でも扱える軽量なダガー、ショートソード、片手斧などを探して回収するのが賢明です。
