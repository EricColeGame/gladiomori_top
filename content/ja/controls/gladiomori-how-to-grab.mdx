## Gladio Moriのグリップと物理演算システムの仕組み

掴み操作が単一の汎用ボタン（`R1`や弱パンチ＋弱キックなど）に割り当てられている従来の格闘ゲームとは異なり、『*Gladio Mori*』は完全に物理演算とキーフレーム主導のアニメーションエンジンで動作します。本作のキャラクターモデルは、装備を持ったり相手と接触したりする際に固定のロックオンアニメーションに依存しません。すべての四肢は、Move Editor（技エディター）やデフォルトの構えで設定された物理状態、関節制限、グリップのオン/オフ切り替えに従って挙動します。

プレイヤーが「掴み（Grabbing）」について疑問を持つ場合、主に以下の2つの異なるアクションを指しています：
1. **武器の把持（Holding）：** メインハンドとオフハンドを武器の柄、柄頭、またはポメルにロックするように設定する。
2. **ダイナミックな組み技 / 接触（Grappling）：** 開いた手や握り拳を使って相手の体を操作し、四肢を捕らえたり、近距離で組み合ったりする。

*Gladio Mori*におけるすべての攻撃は、内部タイムライン上で実行される一連の物理ポーズであるため、そのタイムフレーム中に手がアクティブな把持状態として明示的に定義されていない限り、オブジェクトを掴むことはありません。[Gladio Mori Steam コミュニティハブ](https://steamcommunity.com/app/2689120)を確認すると、カスタムアニメーションを作成する初心者が最も頻繁に直面する壁の1つが、このグリップ関連のトラブルであることがわかります。

| グリップタイプ | メカニクスの概要 | 主な用途 | リスク要因 |
| :--- | :--- | :--- | :--- |
| **プライマリ片手持ち** | デフォルトの手が武器のグリップノードにロック | 素早い刺突、ショートソード、レイピア | 強い衝撃を受けた際の武装解除確率が高い |
| **両手持ち（デュアルグリップ）** | 両手が武器のノードにアクティブに割り当て | グレートソード、長柄武器、重い処刑斬り | 肘が曲がりすぎているとリーチが低下 |
| **ダイナミッククリンチ / 組み** | 開いた手が相手のラグドール関節と衝突 | 武装解除、体勢崩し、至近距離からの投げ | リーチ動作中にカウンターを受けるリスクが高い |
| **ハーフソーディング** | 利き手で柄を握り、逆手で刀身を掴む | 鎧への刺突、高精度の制御 | 斬撃の軌道と純粋なスイングの勢いが制限される |

## Gladiomori How to Grab：スタンス設定のステップバイステップ手順

両手武器を使っているのに片手でしか振れないという問題が発生する主な原因は、スタンス（構え）の設定にあります。デフォルトのアイドルポーズでサブの手が武器を持つように設定されていない場合、戦士は片手でしか武器を持たずにスポーンしてしまいます。

これを解決するには、Move Editor内でアイドルスタンスと基本移動ループを設定する必要があります。グリップを修正するには、以下の詳細な手順に従ってください：

```
[メインメニュー] -> [Move Editor / Stance Manager] -> [武器プロファイルを選択]
   │
   ├──> [スタンスを選択: Idle / Neutral]
   │       │
   │       ├──> 左手の関節を選択 -> 状態を「Hold / Grab」に設定
   │       └──> 右手の関節を選択 -> 状態を「Hold / Grab」に設定
   │
   └──> [オフハンドを武器の柄 / グリップポイントにスナップ] -> [スタンスを保存]
```

### 1. キャラクターのスタンス設定を開く
カスタムファイターまたは技エディターを開きます。使用する予定の特定の武器プリセット（ロングソード、ポールアックス、カタナなど）を読み込みます。

### 2. アイドルスタンスの手の状態を設定する
**Idle Pose**（アクティブな攻撃を行っていないときに戦士が維持する基本ポーズ）に移動します。利き手と逆の手の両方のノードを確認してください。Steamフォーラムで共有されているプレイヤーの経験則によると、アイドルスタンスでは両手を個別に「Hold」に切り替える必要があることを見落としがちです。オフハンドが「Free」または「Ragdoll」に設定されていると、腕が体格の横で力なく揺れてしまいます。

### 3. 手を武器のボーンに固定（アンカー）する
対象の手のIK（インバースキネマティクス）ポイントを、指定された武器のグリップスロットに直接スナップさせます。グリップの衝突判定半径が武器モデルと綺麗に重なるように調整してください。

| 設定ステップ | 設定対象 | 推奨設定 | よくあるミス |
| :--- | :--- | :--- | :--- |
| **ステップ 1: スタンス状態** | 手の把持プロパティ | `Hold` / `Lock to Object` | サブの手を`Relaxed`のままにする |
| **ステップ 2: IKスナップ** | 手の位置ボーン | 武器の柄ボーンにスナップ | ボーンスナップを行わず空中に手を配置する |
| **ステップ 3: タイムライン確認** | キーフレーム0の遷移 | ループ全体でグリップを維持 | スタンスループ中にグリップがオフになる |
| **ステップ 4: 筋肉の緊張度** | 手首/肘の剛性（Stiffness） | 中〜高（65〜85%） | 0に設定してしまい、手首が脱力する |

## 両手武器のキーフレーム設定

アイドルスタンスで両手で武器を正しく握れるようになったら、戦闘時の各キーフレームにわたってその接続を維持する必要があります。スイング全体を通して**gladiomori how to grab**を習得する際、タイムラインの継承を理解することは極めて重要です。

攻撃アニメーションがアイドルスタンスから振りかぶりへと移行する際、アニメーションシステムはすべてのキーフレームでグリップが維持されているかを読み取ります。あるキーフレームでサブの手にグリップフラグが設定されていない場合、オフハンドは即座に武器を離してしまい、大剣の斬撃が無様な弱い片手スイングになってしまいます。

| キーフレーム段階 | 左手の状態 | 右手の状態 | 運動学的な目的 |
| :--- | :--- | :--- | :--- |
| **キーフレーム 0（ニュートラル）** | ロック（Hold） | ロック（Hold） | 武器のバランスとアライメントを安定化 |
| **キーフレーム 1（振りかぶり）** | ロック（Hold） | ロック（Hold） | 肩と体幹全体にトルクを蓄積 |
| **キーフレーム 2（頂点 / タメ）** | ロック（Hold） | ロック（Hold） | レバーアームの位置エネルギーを最大化 |
| **キーフレーム 3（インパクト）** | ロック（Hold） | ロック（Hold） | 剛体コライダーを通して質量を伝達 |
| **キーフレーム 4（フォロースルー）** | ロックまたは解除* | ロック（Hold） | 片手でリーチを伸ばすための任意のリリース |

*\*注：コミュニティの報告によると、フォロースルーの後半段階（キーフレーム4）で意図的にオフハンドを離すと、硬直の回復速度が一時的に低下するものの、武器のリーチを最大15%伸ばすことができます。*

### 物理トルク下でのグリップ安定性の維持
*Gladio Mori*では、重い武器の衝突によってキャラクターの関節に強い回転トルクが逆流します。手のグリップ拘束の剛性が低いと、高速での鍔迫り合いや衝突の際に武器が指から弾き飛ばされてしまいます。

エディター内での推奨設定：
- メイン武器の**Grip Strength（グリップ強度）**を最大に設定する。
- パリィ時にオフハンドが外れてしまわないよう、前腕の**Joint Rigidity（関節剛性）**を少なくとも70%に設定する。
- キーフレームの補間カーブによって、両手がキャラクターの本来の腕の長さを超えて引き離されないよう常に確認してください。超えてしまうと物理エンジンによって強制的に片手が外されます。

## 試合中の組み技とダイナミックグラップリング

武器を持つだけでなく、プレイヤーは敵を武装解除したり、バランスを崩したり、抑え込んだりするために、相手に対する**gladiomori how to grab**の方法を常に模索しています。ダイナミックな組み技は、あらかじめ決められた投げモーションではなく、リアルタイムのラグドール衝突物理に依存するため、ゲーム内で最もテクニカルな要素の1つです。

```
接近角度（斜め） ──> 武器のリーチをくぐる ──> 開いた手のIKを伸ばす
                                                        │
武装解除 <── 相手の手首や鎖骨に手のノードをロック <──────────┘
```

実戦で効果的な掴みやクリンチを実行するには：

1. **素手またはフリーハンドのスタンスを作成する：** 現在両手武器のグリップにロックされている手で相手の体を掴むことはできません。片手が自由になるスタンスや技を設計する必要があります（例：片手剣、短剣、または素手）。
2. **手の衝突判定を掴みモードに設定する：** カスタム技において、敵の四肢と衝突した際に手がアクティブな把持状態に移行するよう、手のひらを開いたリーチキーフレームを設定します。
3. **レバレッジ（てこの力）が効きやすい衝突ゾーンを狙う：** 最適な掴みターゲットは、相手の武器を持つ手首、首/鎖骨、そして腰です。敵の武器側の手首を掴むとスイングの勢いを無力化でき、素早い柄頭（ポメル）打ちや短剣での刺突カウンターを叩き込めます。

| クリンチ技術 | 対象関節 | 戦術的目標 | カウンター対策 |
| :--- | :--- | :--- | :--- |
| **手首コントロール** | 武器側の手首 | 相手の武装解除、または前方への斬撃を阻止 | 素早いバックステップやポメルプッシュ |
| **鎖骨引き** | 胸部上部 / 首 | バランスを崩し、足払いの起点を作る | 強力な下方向への肘打ち |
| **腰タックル** | 骨盤 / 脊椎下部 | 相手を床に倒して抑え込む | スプロール（足を引いて重心を下げる）と膝蹴り |
| **ブレードキャッチ（危険）** | 敵武器の柄 | 長柄武器のてこの作用を瞬時に止める | 刀身の引き戻しによる指の切断 |

## よくある掴みバグとグリップの不具合のトラブルシューティング

*Gladio Mori*はアニメーションタイムラインとソフトボディラグドール物理を融合しているため、いくつかの典型的な設定ミスによって手の挙動が破綻することがあります。以下に、最も頻繁に発生する問題の診断と解決策をまとめました。

### 「片方の手しか武器を持たない」バグ
試合開始時に戦士が片手でしか武器を持たず、サブグリップを無視してスポーンするという現象がコミュニティで頻繁に報告されています。

* **原因：** エディター上でサブの手が見た目上は武器にスナップしているものの、基本スタンスで「Hold」トグルが無効になっているか、手のIKが武器ボーンではなくワールド座標に固定されています。
* **修正方法：** Move Editorに再度入り、アイドルスタンスを選択してオフハンドの関節をクリックし、アタッチ先端が武器のサブグリップボーンに直接ペアレント（親付け）されているか確認してください。

### スイング開始時の武器すっぽ抜け
攻撃を開始した瞬間に、敵に当たる前に武器が手から吹き飛んでしまうことがあります。

* **原因：** キーフレーム間での両手の間隔が、キャラクターの腕のリーチを超えています。キーフレーム1で腕の骨格構造が許容する以上に両手が離れてしまうと、物理エンジンはそれを不可能な関節状態とみなし、グリップの拘束を強制解除します。
* **修正方法：** 3Dビューポートですべてのフレームにおける手の間隔を確認してください。スイング中、両手首の間の距離を一定に保つように修正します。

| 症状 | 根本的な原因 | 解決策 |
| :--- | :--- | :--- |
| オフハンドが即座に武器を離す | スタンスのグリップフラグが未設定 | アイドルスタンスのフレーム0でサブの手を`Hold`に設定 |
| 武器が激しく振動して宙に飛ぶ | インバースキネマティクス（IK）の過伸展 | リーチを縮め、肘を体幹に近づける |
| クリンチ時にオフハンドが相手を空振りする | 伸ばす軌道が狭すぎる | 手を伸ばすキーフレームで手のひらの衝突判定ボックスを広げる |
| 武器が手の中で制御不能に回転する | グリップの剛性設定が低すぎる | スタンスのプロパティで手首の回転摩擦を高める |

## 高度なグリップカスタマイズ：片手 vs 両手

武器の掴み方によって、戦闘スタイルは劇的に変化します。技セット内でグリップを切り替えられるようにしておけば、重装甲の相手と軽装甲の相手に臨機応変に対応できます。

**gladiomori how to grab**をマスターする際は、完全な片手持ち、ダイナミックな両手持ち、そしてハイブリッドスタンスの戦術的な長所と短所を考慮してください：

| 属性 | 片手グリップ | 両手デュアルグリップ | ハーフソーディンググリップ |
| :--- | :--- | :--- | :--- |
| **有効リーチ** | 長い（腕を100%伸展） | 中程度（65〜80%伸展） | 短い（40〜55%伸展） |
| **インパクトの運動エネルギー** | 中程度 | 非常に高い | 集中した刺突力 |
| **受け流し（偏向）耐性** | 低い（パリィされやすい） | 高い（スイング軌道を維持） | 最大（強固なレバーアーム） |
| **武装解除のリスク** | 激しい鍔迫り合いで35% | 激しい鍔迫り合いで10%未満 | ほぼ0% |
| **空いた手の実用性** | 組み技/パンチが可能 | なし（両手が拘束） | 足払い/盾の引っ掛けが可能 |

効果的な**gladiomori how to grab**の技術を理解することは、実戦的な技セットを作成するための基盤です。アイドルスタンスで両手を正しく構成し、キーフレームのタイムライン状態をロックし、適切な物理的リーチの円弧を設計することで、厄介なグリップの不具合を排除し、圧倒的な精度でアリーナを支配できるようになります。

## よくある質問（FAQ）

### Gladio Moriで片手しか持っていない武器を両手で掴むにはどうすればいいですか？
この一般的な問題を解決するには、Move Editorを開いて基本の**Idle Stance（アイドルスタンス）**を確認してください。戦士のオフハンド（逆手）ノードをクリックし、動作状態を**Hold**に設定した上で、手のIKを武器のサブグリップボーンに直接スナップさせます。このHoldフラグがキーフレーム0で有効になっていることを確認してください。そうでない場合、スポーン時にデフォルトの片手持ちモードになってしまいます。

### Gladio Moriでは相手の武器を掴んで武装解除することはできますか？
はい、可能です。相手の武器を持つ手首や柄を狙うフリーハンド（空いた手）のアクションを設計すれば、物理的な衝突によって相手のスイングの勢いを止めることができます。手首掴みと体幹の引き寄せ、または足払いを組み合わせることで、相手の手から武器を奪い取るのに十分なトルクを生み出すことができます。

### 武器を振った瞬間にキャラクターが落としてしまうのはなぜですか？
これは通常、スイングアニメーションのキーフレームによってキャラクターの腕が物理的な長さを超えて引き伸ばされている場合に発生します。手の間の距離がキャラクターモデルの骨格限界を超えると、骨格の崩壊を防ぐために物理エンジンが強制的にグリップ拘束を解除します。手のキーフレーム間の距離を近づけることで修正できます。

### 戦闘中に両手持ちから片手持ちに切り替えることはできますか？
はい、可能です。技セットプロファイル内で別々の連携技をプログラムできます。例えば、両手での振り下ろし攻撃から始まり、フォロースルーのキーフレームでオフハンドを離して、リーチを最大限に活かした片手突きへと移行する一連の攻撃シーケンスを作成することができます。
