## 戦闘メカニクスと臓器ターゲティングの操作

本作のアリーナ戦闘は、完全に「臓器ベースの損傷エンジン」を中心に展開します。相手の重要臓器を貫けばそのラウンドは即座に終了し、主要動脈を切断すれば急速な失血死を引き起こします。コントローラーの操作系は、いわばプレイヤーの手術用メスです。どのボタン操作がどの負傷タイプに対応しているのかを把握することで、重装甲の敵にも柔軟に対処できます。

```
[ 攻撃のヒット ]
        │
        ├── プレートアーマーにヒット ───► 弾かれる / スタミナ消費
        │
        ├── 筋肉組織にヒット         ───► 手足の攻撃速度・硬直復帰の低下
        │
        ├── 主要動脈にヒット         ───► 持続的な出血 / 最終的な昏倒
        │
        └── 重要臓器にヒット         ───► 即座にアリーナ敗退（即死）
```

これらの一撃必殺となる攻撃を当てるには、攻撃モーションの発生中にスティックを適切に操作する必要があります：

| 狙う部位 | 必要なXbox入力手順 | 見込める戦闘効果 |
| :--- | :--- | :--- |
| **喉 / 首（動脈）** | RS上 + RB（前進刺突） | 無装甲のターゲットなら即座の失血死または首の切断 |
| **脇の下 / 関節（筋肉）** | RS斜め下 + RT（薙ぎ払い斬り） | 敵の武器を振る速度が40%以上低下 |
| **心臓 / 肺（重要臓器）** | LB + RS前 + RB（渾身の刺突） | 胸当ての隙間をすり抜け、バイパスして即座にKO |
| **股間 / 大腿動脈** | RS下段スイープ + RTリリース | 大量の出血ダメージを与え、敵の移動速度を著しく低下 |

右スティックをこれら脆弱な急所へスムーズに倒せるよう**gladiomori xbox controls**を微調整できるかどうかが、駆け出しの剣闘士と歴戦のチャンピオンを分かつ決定的な差となります。公式ストアの詳細やアップデート情報は、[Xbox Gladio Mori ストアページ](https://www.xbox.com/en-US/games/store/gladio-mori/9n3vnl013jrf)で確認できます。

## 防御システム：パリィ、ブロック、フットワーク

攻撃がどれほど優れていても、最初の激突を生き残れなければ勝利はありません。防具は体の特定の部位しか保護しないため、防御の入力は受動的ではなく能動的（プロアクティブ）に行う必要があります。敵の刃が肩当ての隙間から滑り込んできた場合、左トリガーでただガードを押し続けていても命は救えません。

### Xboxコントローラーにおける通常ブロックとアクティブパリィの比較

| 防御アクション | コントローラー操作 | リスクレベル | 戦術的リターン |
| :--- | :--- | :--- | :--- |
| **静止ブロック** | **LT**を長押し | 低 | 盾や防具で打撃を吸収。武器の安定性を消費 |
| **方向指定ディフレクション** | **LT**長押し + **RS**で角度を調整 | 中 | 刃を自身の正中線から外れる方向へと受け流す |
| **タイミングリポスト** | インパクト直前に**LT**をタップ | 高 | 相手を大きくよろめかせ、無防備な急所を露出させる |
| **回避ピボット** | **LS**後方/側面 + **A**をタップ | 中 | 攻撃との接触を完全に回避し、武器スタミナを温存 |

タイミングを合わせたリポストを繰り出す際、プレイヤーコミュニティの知見では、相手の切先を見るのではなく「腰の動き」に注目したほうが、攻撃が放たれるリリースタイミングを格段に見極めやすくなるとされています。

## ムーブセットのカスタマイズとコントローラー設定

Gladio Moriの大きな特徴の一つが、コミュニティが作成したカスタムムーブセットをコントローラーのレイアウトへ直接割り当てられる機能です。あらかじめ用意されたプリセットのアニメーションに縛られることなく、基本的な入力操作を自分好みのオリジナル連続技へと昇華させたコミュニティスタイルを作成・ダウンロードできます。

| ムーブセットカテゴリー | 推奨コントローラー配置 | 最適な戦闘スタイル |
| :--- | :--- | :--- |
| **歴史的フェンシング** | 刺突にRB、高低のピボットにRS | 長いリーチを活かした戦術的なレイピア＆ロングソード戦 |
| **ブロウラー / 近接インファイト** | 重い薙ぎ払いにRT、組み付きにXボタン | アグレッシブなグラディウス、シールドバッシュ、ダガー戦 |
| **アクロバティック / フェイント重視** | LBパドルにBボタン（キャンセル）を割り当て | 予測不能な緩急、陽動、フェイントによる釣り出し |
| **ゾーンディフェンス** | RTに広範囲の水平斬り | 4人乱戦（フリーフォーオール）での複数敵の制圧 |

### Xbox Series X|Sでのムーブトリガーのカスタマイズ手順

1. メインメニューから**Moveset Lab（ムーブセットラボ）**に入ります。
2. 希望する武器タイプ（例：ショートソード、両手斧、スピアなど）を選択します。
3. 特定のコントローラーの組み合わせ（例：頭上からの処刑斬りに**LB + RT**など）にアニメーションプロファイルを割り当てます。
4. 物理トレーニング用の木人形部屋に入り、武器の振り速度や筋肉へのダメージ閾値をテストします。
5. カスタマイズしたプロファイルを、有効なロードアウトスロットに保存します。

Xbox Elite ワイヤレス コントローラー シリーズ 2 を使用している場合は、**B**（キャンセル/フェイント）と**A**（ダッシュ）の入力を背面パドルに割り当てることで、両手の親指を常に左右のスティックから離さずにプレイできます。

## デッドゾーン、感度、本体設定の最適化

Gladio MoriはXbox Series X|Sにおいて4K解像度・60fps以上で軽快に動作するため、入力遅延はごくわずかです。ただし、物理的な刃の慣性を考慮してスティックの反応曲線を調整していないと、デフォルトのコントローラー設定では操作が緩く感じられる場合があります。

| 設定項目 | 推奨値 | 重要な理由 |
| :--- | :--- | :--- |
| **RS 水平感度** | 6.5 – 7.5 | 精度を犠牲にすることなく、刃の構えを素早く変更可能 |
| **RS 垂直感度** | 5.0 – 6.0 | 水平な刺突時に、意図せず下方へ斬り落とす誤操作を防止 |
| **内部デッドゾーン (LS & RS)** | 3% – 5% | スティックのドリフトを防ぎつつ、瞬時の反応速度を維持 |
| **外部デッドゾーン** | 95% | わずかな倒し込みで最大のスイング慣性に到達させる |
| **トリガー有効化の閾値** | 即時（ヘアトリガー） | RT/RBによる打撃の発生遅延を極限まで低減 |

コミュニティからの報告でも、右スティックの内部デッドゾーンを下げることで、重厚なプレートアーマーの狭い隙間を狙う際の微細なエイム精度が劇的に向上することが確認されています。

## よくある操作トラブルと解決策

闘技場では、物理演算の競合やハードウェアの些細な問題によって攻撃のタイミングが狂ってしまうことがあります。よくあるコントローラーの不具合は、以下のトラブルシューティング表を参考に素早く解決してください：

| 発生した問題 | 考えられる原因 | 解決策・対処法 |
| :--- | :--- | :--- |
| **武器のスイングが「引っかかる」** | トリガーのデッドゾーンが低すぎる | 設定でRTのリリースの閾値を引き上げる |
| **刺突の軌道がズレる** | 軸のスムージングが有効になっている | ゲームプレイ設定でコントローラーのエイムスムージングを無効化する |
| **画面分割時に入力が重複する** | プレイヤープロファイルが未割り当て | Xboxガイドボタンから各ゲームパッドを個別に再同期する |
| **オンラインでパリィが抜ける** | 回線遅延 / 入力パケットロス | パフォーマンス表示を有効化し、有線LAN接続に切り替える |

## よくある質問（FAQ）

### Gladio MoriのXbox操作は完全にリマップできますか？
はい。Gladio Moriはオプションメニュー内でゲーム内コントローラーの完全なリマップに対応しています。さらに、Xbox本体標準の「Xbox アクセサリ」アプリを使用すれば、カスタムプロファイルの作成、スティックの応答曲線の調整、物理ボタンの割り当て変更も行えます。

### コミュニティのムーブセットはXboxコントローラーでどうやって発動しますか？
エディターでカスタムムーブセットをダウンロードまたは作成したら、アクティブなロードアウトスロットにバインドします。これらのアニメーションはデフォルトの振りと置き換わり、通常の攻撃入力（**RT**、**RB**、または**LB + RT**などのモディファイアの組み合わせ）で発動できるようになります。

### Gladio MoriはXbox本体でのマウスとキーボード操作に対応していますか？
Gladio MoriはPC版ではネイティブにキーボードとマウスをサポートしていますが、Xbox Series X|Sのコンソール版は標準のXboxワイヤレスコントローラー向けに最適化されています。家庭用ゲーム機向けのマウス・キーボード対応が拡張されているかどうかは、メインメニュー内の最新パッチノートをご確認ください。

### gladiomori xbox controlsのデフォルト設定だと攻撃の振りが遅く感じるのはなぜですか？
Gladio Moriの攻撃は、アーケードゲーム的な固定フレームではなく、リアルな物理演算と筋肉の損傷状態に依存しています。キャラクターの腕の筋肉にダメージを受けていると、武器を振る速度が物理的に低下します。また、体の自然な慣性に逆らって無理に剣を振ると刃の速度が落ちてしまいます。左スティックを使って腰を回転させ、打撃に体重を乗せるように振ることで最大の速度を生み出せます。
