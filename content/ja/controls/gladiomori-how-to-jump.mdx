## Gladio Mori通常版におけるジャンプの実態

[Gladio Mori Steam コミュニティハブ](https://store.steampowered.com/app/2689190/Gladio_Mori/)から通常版のゲームを起動した際、一般的な対戦アクションやプラットフォーマーのようにスペースキーでジャンプできると期待するかもしれません。しかし、『Gladio Mori』は現実の西洋古流剣術（HEMA）とリジッドボディ物理演算を核としてゼロから構築されています。

| 機能 | バニラ版の状態 | MOD / 自作アニメーション適用時 |
| :--- | :--- | :--- |
| **専用ジャンプキー** | なし | スクリプトフック経由で設定可能 |

基本ゲームには標準で空中アクション用ボタンが用意されていないため、**gladiomori how to jump**と検索するプレイヤーの多くは、ソーシャルメディア上で剣闘士が迫り来る刃を飛び越えるバイラル動画を目にして調べているのが現状です。

## バニラでの代替案：自作アニメーションによる跳躍の再現

通常エンジンのキー割り当てには空中機動がありませんが、『Gladio Mori』には非常に奥深いアニメーションエディターが標準搭載されています。プレイヤーは戦士の骨格、関節、筋肉の張力をフレーム単位で操作し、上方向への推進力を生み出すことができます。

システムファイルを改変せずに**Gladio Moriでジャンプする方法**を求める場合、その答えは物理エンジンが重心をどのように処理しているかを理解することにあります。骨盤のボーンを急激に引き上げつつ、爆発的な脚の伸展を加えることで、ラグドールを一時的に地面から浮かせることが可能です。

### ステップ解説：バニラで作る「ホップストライク（跳躍斬り）」

1. **アニメーションエディターを開く**: トレーニングメニューからカスタムムーブビルダーを選択します。
2. **屈んで位置エネルギーを溜める**: 最初の3〜5フレームで腰を落とし、両膝を曲げます。
3. **上方へ爆発的に跳ぶ**: 膝をピンと伸ばしながら、2〜4フレームかけて骨盤関節をY軸沿いに鋭く上方向へ引き上げます。
4. **脚を抱え込む**: 攻撃の最中に両足を胴体側へ引き込み、対地クリアランス（滞空時の高さ）を最大化します。
5. **広めのスタンスで着地する**: 降下時は衝撃を吸収して転倒を防ぐため、両足を肩幅よりわずかに広く開きます。

| フレーム区間 | 対象関節 | 意図した動作 | 物理的効果 |
| :--- | :--- | :--- | :--- |
| **第1〜4フレーム** | 骨盤、両膝 | 下方向へ圧縮 | 重心を下げ、力を蓄積する |
| **第5〜8フレーム** | 胴体、腰 | 上方向への弾き＋前傾 | 当たり判定カプセルを地面から浮かせる |
| **第9〜14フレーム** | 利き手、両腕 | 振り下ろし軌道の斬撃 | 腕の急速な振り下ろしがわずかな浮力を生む |
| **第15〜20フレーム** | 両足、足首 | 軽く曲げた状態で接地へ戻る | 勢いを殺し、ノックダウンを防ぐ |

## MODによる空中メカニクス：自由なジャンプ機能の解放

アクロバティックなアリーナ戦闘で話題となった動画の正体は、サードパーティ製MODによるものです。TikTokやDiscordなどのプレイヤーコミュニティからの報告によると、有志のクリエイターたちが『Gladio Mori』に専用のジャンプスクリプトを導入しました。

これらのコミュニティ製MODは物理エンジンに直接干渉し、規定の重力制約をオーバーライドするか、スペースキー入力時にプレイヤーのルートボーンへ瞬間的な上向きインパルス力を付与します。

```
[インパルスイベント: キー押下 (Space)]
         │
         ▼
[接地判定 == True]
         │
         ├── True  ──> [上向きインパルスベクトルを適用 (0, +Force, 0)]
         │                  │
         │                  ▼
         │             [空中状態フラグ起動 ＆ 物理減衰処理]
         │
         └── False ──> [入力を無視 / 2段ジャンプをキャンセル]
```

### MOD別ジャンプタイプの比較

コミュニティのモッダーたちは様々なスタイルの空中機動を検証してきました。以下の表は、代表的なカスタムMODの挙動をまとめたものです。

| MODカテゴリー | 発動入力 | 到達高度 | 戦術的優位性 | リスク要因 |
| :--- | :--- | :--- | :--- | :--- |
| **インパルススクリプト** | スペースキー | 低〜中 | 低い足元への薙ぎ払いを回避可能 | 着地時にラグドールが躓きやすい |
| **アニメーション上書き** | 攻撃コンボ入力 | 予測可能な放物線 | 高威力の振り下ろし一撃 | 上昇中に刺突攻撃を受けやすい |
| **低重力（ムーン）調整** | パッシブ切替 | 非常に高い | 滞空時間が大幅に延長 | リアルな戦闘物理が完全に崩壊する |

**Gladio Moriでジャンプする方法**を試すためにクライアントMODの導入を検討する場合、対戦相手も全く同じ構成にしていない限り、通常のマルチプレイマッチングでは同期ズレ（デシンク）や予期せぬラグドール崩壊が発生することにご留意ください。

## 戦術分析：垂直移動のリスクとリターン

動脈へのクリーンヒットや首への刺突一閃で決着がつく本作において、空中戦は本質的に極めて危険な行為です。足が地面から離れた瞬間、方向転換の自由が失われるため、冷静な対戦相手にとっては格好の標的となります。

実戦で**gladiomori how to jump**を極めようと何時間も費やす前に、以下の戦術的バランスを慎重に吟味してください。

| 戦闘指標 | 地上での防御 | 空中・跳躍マニューバ |
| :--- | :--- | :--- |
| **方向転換の敏捷性** | 高い（即座の旋回と後退が可能） | ゼロ（放物線の弾道軌道に固定） |
| **被弾面積の露出** | 低い（盾と構えで急所を防護） | 致命的（股間、脚部、喉が無防備になる） |
| **武器の運動エネルギー** | 安定かつ予測可能 | 振り下ろし攻撃において極めて高い |
| **リカバリー時間** | 素早い（即座に反撃の刺突が可能） | 遅い（着地時のよろけフレームが発生） |
| **カウンターへの脆弱性** | 通常のフェイント程度 | 刺突による確定反撃を食らいやすい |

### 跳躍攻撃の有効な活用例

* **予測しやすい下段払いの迎撃**: 相手が両手持ち武器で足首ばかりを執拗に狙ってくる場合、タイミングを合わせた小ジャンプで刃を完全に飛び越せます。
* **高めの盾の突破**: 前方へ小さく跳ぶことで、相手が掲げたスクトゥムやバックラーを飛び越えて頭上からの一撃を叩き込めます。
* **視覚的な撹乱**: 不規則な上下動を織り交ぜることで、左右・前後の標準的な間合い管理に慣れた対戦相手を動揺させることができます。

## 代替案：アリーナを制する4つの必須地上フットワーク

跳躍には重大なリスクが伴うため、トップクラスの決闘者たちは一度も砂から足を離すことなく、洗練された地上移動のみで攻撃を回避します。**Gladio Moriでのジャンプ**がうまくいかない場合は、MODに頼る前に以下のフットワーク技術を習得することで、勝率を飛躍的に向上させられます。

1. **イン・アンド・アウト・ドリフト**: 相手の最大射程のギリギリ外側に位置を取り続けます。移動キーを小刻みに入力して攻撃を誘い、数センチだけ引いて空振りを誘発させ、即座に踏み込んで反撃します。
2. **オフライン・ピボット（軸ずらし旋回）**: 直線的に後退するのではなく、相手の利き手とは逆のサイドへ回り込むように動きます。多くの薙ぎ払いアニメーションは、体を交差させる動きを強いられると斬撃の威力が低下します。
3. **しゃがみ潜り（ダッキング）**: しゃがみキーを維持することで、首を狙った水平の斬撃を完全に下へ潜り込んでやり過ごせます。重心の安定を保ち、足を接地させたまま即座の刺突へ移行できます。
4. **スタッターステップ**: 方向移動を一瞬だけタップして胴体の位置をずらし、迫り来る刺突の射線から外れつつ、自らの武器の攻撃態勢を維持します。

## よくある質問（FAQ）

### Gladio Moriでジャンプするにはどのボタンを押しますか？
ゲームの通常版には、デフォルトでジャンプするボタンはありません。プレイヤーが自由にジャンプしているのを見かけた場合、サードパーティ製の物理MOD、スペースキーなどに割り当てたカスタムスクリプト、またはムーブエディターで特定フレームを設定した自作アニメーションのいずれかを使用しています。

### マルチプレイでジャンプMODを使用するとBANされますか？
カジュアルなカスタムロビーでは、双方が同一のMODファイルを導入していれば基本的に問題なく遊べます。しかし、通常の公式マッチングで物理パラメータを変更する移動スクリプトを使用すると、サーバーとの同期ズレやゲームのクラッシュ・不安定化を引き起こす原因になります。

### なぜ開発者はジャンプ機能を付けずにGladio Moriを設計したのですか？
開発陣が西洋古流剣術（HEMA）のリアリズムを徹底して優先したためです。甲冑または平服での剣術の決闘において、跳躍はバランスを著しく崩し、パリィ（受け流し）を不可能にし、相手のカウンター刺突に対して急所を完全に晒してしまう悪手となるからです。

### 初心者がGladio Moriでジャンプ方法を練習する価値はありますか？
いいえ、おすすめしません。初心者はまず、間合いの把握、武器のリーチ管理、体勢の立て直し、そして戦闘エディターの基本構造を習得することに集中すべきです。ジャンプで攻撃を飛び越えようとしても、軌道が単調になるため、ほとんどの場合は空中で刺し貫かれて終わる結果になります。
