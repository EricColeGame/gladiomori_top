## 戦闘メカニクス：Gladio MoriがHPゲージを廃止した理由

一般的なアリーナ格闘ゲームのように画面上の緑色の体力ゲージやガードゲージを削り合うのではなく、『Gladio Mori』の戦闘は解剖学に基づいた人体の損傷によって成り立っています。相手のライフをゼロにするのではなく、露出した皮膚や急所に向けて物理的な刃を正確に突き立てる必要があります。

### 臓器・組織ダメージの階層構造

あらゆる斬撃や刺突は、体内組織に対して深さ・角度・衝突速度を詳細に計算します。

* **筋肉：** 前腕やすねを切り裂かれると筋肉の機能が損なわれます。腕を負傷すると剣の振りが遅くなり威力が低下し、脚を負傷するとステップや回避がままならなくなります。
* **動脈：** 深い刺突や大きく振り抜いた斬撃は太い血管を断ち切ることがあります。動脈が破裂すると大量出血が始まり、意識を失う前に相手を倒せるかどうかのタイムリミットとの戦いになります。
* **急所：** 心臓、脊髄、脳、喉など、防具に守られていない急所への直撃は即死をもたらします。

| 負傷の重症度 | 影響を受ける部位 | ゲーム内の即時影響 | 戦術的対抗策 |
| :--- | :--- | :--- | :--- |
| **軽度 / 表皮** | 皮膚の表層、四肢の先端 | わずかなよろめき、スタミナ微減 | 体勢の立て直し、必要に応じて持ち手を変更 |
| **中度 / 筋肉** | 上腕二頭筋、ハムストリング、肩 | 攻撃速度低下、パリィ弱体化、足引きずり | 防御重視の構え、間合いの維持 |
| **重度 / 血管** | 頸動脈、大腿動脈、胴体深部 | 激しい出血、急速なスタミナ減少 | アグレッシブに攻めて早期決着を狙う |
| **致命傷 / 急所** | 心臓、頸部切断、脳幹 | 即死 / ラウンド終了 | 常に盾や鍔を前方に向けて急所を守る |

この過酷でリアルな生理学的モデルにより、**gladiomori console release**はボタン連打ではなく、防御の判断と刃の角度調整が決定打となる頭脳戦へと昇華されています。

アリーナに足を踏み入れる剣闘士にとって、防具の特性を把握することは生死を分ける知識です。

コンソール版で重装甲の敵と対峙した際、胸当てに向かってブロードソードを何度も振り下ろすのは、武器の刃を潰し貴重なスタミナを浪費するだけです。相手の大振りを誘い、ステップでかわしながら、防具のない関節の継ぎ目へ正確に刃を滑り込ませなければなりません。

## コミュニティ製技セット、カスタムモーション、コンソール操作

PC版で最も絶賛された要素の一つが、独自の構えや予測不能なコンボ、オリジナルの攻撃モーションをプレイヤー自身が作成できる「コミュニティ製技セット（Movesets）」機能でした。

**gladiomori console release**において、Plebeian Studioはこの自由度の高いサンドボックス機能と、ゲームパッドでの直感的な操作感を見事に融合させています。

```
カスタマイズの流れ：
1. ベースとなる武器種を選択（例：ロングソード、槍、レイピア）
2. 構えのプリセットやコミュニティで検証されたモーションノードを割り当て
3. 主要な技をゲームパッドのトリガーや前面ボタンにマッピング
4. 練習用ダミーアリーナで攻撃の軌道と硬直フレームをテスト
```

ゲームパッドでは、ツインスティックを活用して攻撃の方向を細かく制御できます。
* **左スティック：** フットワーク、重心移動、踏み込みの勢いを操作。
* **右スティック：** 刃の向き、高低の攻撃角度、パリィの角度を調整。
* **トリガー＆バンパー：** 攻撃の速度、フェイント、相手を掴む組み打ち動作を制御。

コミュニティの報告によれば、ゲームパッド操作に馴染むまでは最初の数時間に少し慣れが必要とされています。しかし、一度マッスルメモリー（筋肉記憶）に刻まれれば、アナログスティックを使って上段からの振り下ろしを急遽刺突へと切り替える動作が、驚くほど自然に行えるようになります。

## 初心者がアリーナで生き残るための必須テクニック

この物理演算格闘ゲームがリアル系剣闘士シミュレーションの初体験となる場合、アーケードゲーム感覚でボタンを連打していると、わずか数秒で砂の上に血を流して倒れることになります。以下の戦術の基本を常に意識してください。

1. **刃筋（アライメント）を意識する：** 防具や肉体に対して刃の腹（平らな面）で叩いても、切断力は大幅に低下します。必ず刃先がスイングの軌道をリードするように振ってください。
2. **出血を放置しない：** 太ももを切られ、血が噴き出し始めたら戦術を変えましょう。長期戦のディフェンスに持ち込む時間はありません。意識が途切れる前に一気に攻めて勝負を決める必要があります。
3. **正中線（センターライン）を制する：** 剣先を常に相手の喉元へ向けて構えましょう。相手にこちらの武器の間合いを迂回させるようプレッシャーを与えます。
4. **フェイントで隙を作り出す：** 上段からの振り下ろしを繰り出すと見せかけて途中で止め、無防備になった相手の脇の下へ下段からの突きへと変化させます。

## よくある質問（FAQ）

### Gladio Moriのコンソール版の発売日はいつですか？
公式の**gladiomori console release**は、Bonus Stage Publishingより2026年9月16日にXbox Series XおよびXbox Series S向けに配信が開始されました。

### コンソール版はローカル画面分割マルチプレイに対応していますか？
はい！コンソール版は1台の本体で同時に2〜4人でのローカル画面共有／画面分割マルチプレイに完全対応しており、オンラインマルチプレイも利用可能です。

### コンソールでオンラインプレイをするにはサブスクリプションが必要ですか？
オフラインでのローカル画面分割プレイには加入は不要ですが、Xboxでのオンラインマルチプレイヤーモードのプレイには、Xbox Game Pass CoreまたはXbox Game Pass Ultimateの有効なサブスクリプションが必要です。

### Gladio Moriに従来の体力ゲージ（HPバー）はありますか？
いいえ、『Gladio Mori』には一般的なHPゲージは存在しません。ダメージは臓器や筋肉に基づいた物理演算ダメージシステムで完全に決定され、骨折による攻撃力低下、動脈切断による致命的な出血、急所への刺突による即死などがリアルに発生します。
