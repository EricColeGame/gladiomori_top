## 解剖学に基づく戦闘：体力ゲージの完全排除

この戦闘エンジンの最大の特徴は、臓器や身体構造に基づくダメージシステムです。一般的な格闘ゲームでは、足のつま先を攻撃しても胸部をクリーンヒットさせても、同じように抽象的なダメージとして処理されます。しかしこのアリーナでは、すべての振り下ろしが物理的な重みを持ち、生理学的な結果をもたらします。

相手を攻撃する際は、防具の装着範囲を見極め、その下にある急所を正確に狙う必要があります。ゲーム内では武器の速度、刃の角度、肉体の抵抗がリアルタイムで計算されます。

| 標的部位 / 負傷タイプ | 即時的なゲームプレイへの影響 | 戦術的な結末 |
| :--- | :--- | :--- |
| **動脈切断** | 急激な失血、画面の彩度低下 | 被害者は意識を失うまでの数秒間で決着をつけなければならない。 |
| **重要臓器（心臓/肺）の貫通** | 即座の行動不能または急速な窒息 | それ以前の状態に関係なく、直ちに致命的な結果を引き起こす。 |
| **上腕二頭筋 / 前腕の切断** | グリップ力の喪失、スイング速度の低下 | 繰り出す攻撃が著しく弱体化し、武器を取り落とす場合もある。 |
| **ハムストリング / 大腿四頭筋の断裂** | 移動能力の喪失、歩行速度の大幅な低下 | 回避の有効性が失われ、間合いの管理が極めて困難になる。 |
| **頭部への強打（脳震盪）** | よろめき、見当識障害、ノックダウン | 相手にとどめの一撃を与える絶好の隙を晒すことになる。 |

試合中に負った怪我は永続的に剣闘士の能力を損なうため、無謀な突撃だけでなく、消極的すぎるプレイも等しく命取りになります。序盤で相手の武器を持つ腕に攻撃を命中させることができれば、相手の攻撃脅威度を大幅に低下させ、残りのデュエルを安全にコントロールできるようになります。

## Xbox決闘者のための必須戦闘戦略

物理的な慣性や武器の重量感を理解せずにアリーナに足を踏み入れると、瞬く間に敗北を喫することになります。対戦に挑む際は、以下の実践的な戦闘戦略を常に心に留めておいてください。

1. **照準ではなく刃先を意識する：** 攻撃の威力は、武器の勢いと先端の位置から生じる運動エネルギーによって決まります。単に攻撃ボタンを押すだけでなく、アナログスティックを繊細に操作して、防具のない露出した肉体へと切っ先を誘導しましょう。
2. **センターラインを制する：** 物理ベースの戦闘では、中心空間を制した者が相手に無理な体勢からの防御スイングを強いることができます。武器の先端を常に敵の急所に向けておくことで、相手の不用意な突進を牽制できます。
3. **出血タイマーを有効に使う：** 相手の主動脈を切断することに成功したら、深追いせず一度下がりましょう。安全な防御間合いを維持し、自身のスタミナを温存しながら、失血によって相手が倒れるのを待つのが賢明です。
4. **フットワークで角度を作る：** 相手の盾を構えている側の外側へと回り込むことで、正面からの突撃では狙えない無防備な脇腹や首元を狙う角度を作り出せます。

## よくある質問（FAQ）

### 『Gladio Mori』Xbox版はクロスプラットフォームプレイに対応していますか？
はい。コンソール版はXboxの完全なクロスマルチプレイヤーに対応しており、他の対応プラットフォームでプレイしているプレイヤーとマッチメイキングや対戦が可能です。

### オンラインプレイにはXbox Game Passの加入が必要ですか？
はい。Xboxネットワーク上の大半の有料マルチプレイヤータイトルと同様に、オンラインマルチプレイヤーモードのプレイにはXbox Game Pass CoreまたはXbox Game Pass Ultimateの有効なサブスクリプションが必要です。ただし、ローカル画面分割対戦やソロ練習モードは、サブスクリプションなしで完全にオフラインでプレイできます。

### 体力ゲージがない場合、ダメージシステムはどのように機能しますか？
本作では、完全にシミュレートされた解剖学的ダメージモデルが採用されています。ヒットポイントゲージを減らす代わりに、攻撃によって筋肉、骨、重要臓器に物理的な損傷が与えられます。心臓や脳の貫通は即死を招き、動脈の切断は致命的な失血を引き起こし、筋肉の損傷は攻撃の威力や移動能力を低下させます。

### Xbox Series Sで『Gladio Mori』を60 FPSでプレイできますか？
はい。本作はXbox Series XとXbox Series Sの両方に最適化されており、滑らかで反応の良い剣戟アクションを保証するため、両機種で60 FPSをターゲットに動作します。Series Xは最大4K解像度で出力され、Series Sは最適化されたダイナミック解像度で動作します。
