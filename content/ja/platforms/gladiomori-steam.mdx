個人クリエイターLittleLegatus氏率いるPlebeian Studioが開発し、Bonus Stage PublishingおよびKorgi Digitalがパブリッシングを手掛ける『Gladio Mori』は、物理演算格闘ゲームのファンから絶大な注目を集めています。ValveのSteamストア上で「非常に好評」のユーザーレビューを獲得している正式版（Ver 1.0）では、その革新的なゲームプレイをベースに、クロスプラットフォーム通信、包括的なModサポート、高度な外見カスタマイズ機能が大幅に拡張されました。

固定されたアニメーションツリーに縛られるのではなく、本作には独自のポーズエディターが搭載されています。プレイヤーは自ら構えを細かく設定し、コンマ数秒単位で太刀筋のタイミングを計算し、個々の攻撃を連携させて自分だけの流麗な武術シークエンスを編み出すことができます。

## 臓器ベースの部位ダメージと部位切断メカニクス

Gladio Moriを支配する根本的な思想は「生物学的な因果関係」です。グラディエーターの頭上にHPバーは表示されません。打撃の進入角度、刃の鋭利さ、運動エネルギー、そして防具のカバー範囲に基づいて、肉体へのダメージが厳密にリアルタイム計算されます。

肩当ての上から金棒（Kanabo）で強打すれば、相手をよろめかせて下層の骨を骨折させる可能性があり、むき出しの喉元をグラディウスで素早く切り裂けば、激しい動脈出血を引き起こして即座に行動不能に追い込めます。

### 解剖学的ダメージ階層

| 負傷タイプ | 対象となる解剖学的部位 | ゲーム内の挙動・影響 | 戦闘継続能力 |
| :--- | :--- | :--- | :--- |
| **筋断裂** | 上腕二頭筋、ふくらはぎ、太もも | 攻撃速度の低下、フットワークの減速 | 中程度の機能低下、防御が脆弱化 |
| **動脈裂傷** | 首、内もも、脇の下 | アリーナの床に持続的な大量出血 | 致命的（時間制限あり、即座の決着が必要） |
| **骨折** | 肋骨、前腕、膝 | よろめきフレームの増加、両手持ちの維持不可 | 重篤、カウンター攻撃に対して極めて脆弱 |
| **バイタル貫通** | 脳、心臓、肺 | 即座の昏倒 / 死亡 | その場で決闘終了（即死） |
| **部位切断** | 手、前腕、下肢 | 武器の強制落下、通常の歩行・移動能力の喪失 | 絶望的状態、地面でのもがき行動に限定 |

刃筋（エッジアライメント）が極めて重要であるため、闇雲に武器を振り回しても、分厚い革や金属プレートに当たって虚しく弾かれるだけです。コミュニティの検証でも、最大の勢いで武器を振り回すことよりも、衝突時の接触角度をコントロールすることのほうが遥かに重要であると報告されています。

## 武具解説：武器種とモジュラー防具

ゲーム本編には、34種類の個性豊かな武器、3種類の歴史的シールド、そして17種類のモジュラー防具パーツが用意されています。防具はそれが物理的に覆っているポリゴン部分しか保護しないため、バックル、関節の隙間、バイザーのスリットのすべてが致命的な急所となります。

### 武器カテゴリーと戦術的役割

| カテゴリー | 代表的な武器 | 主なダメージタイプ | 理想的な戦術的間合い |
| :--- | :--- | :--- | :--- |
| **片手刃** | グラディウス、アーミングソード | 刺突 / 斬撃 | インファイト接近戦。防具のない首や脇の下の隙間を狙う |
| **両手大型刃** | エクセキューショナーズソード、関刀 | 高速広範囲斬撃 | 中距離の間合い管理。露出した前腕や四肢を狙う |
| **長柄武器** | スラストスピア、ハルバード | 刺突 / 打撃 | アウトレンジ戦。安全圏から間合いを完全に支配する |
| **打撃・粉砕武器**| 金棒、フレイル、メイス | 衝撃 / 圧壊 | 重装甲プレートを貫通して内部の骨を粉砕する |
| **素手 / 格闘** | セスタス、素手 | 軽度の打撃 | 最終手段の組み付き。大振りで隙を見せた相手の武装解除 |

## 初心者向けアリーナ戦術ガイド

1. **利き手を死守する：** 利き腕の機能を失うと、武器をその場に落としてしまいます。カスタムコンボを組み立てる際は、腕を相手の眼前に突き出したままになる大振りなポーズは避けましょう。
2. **装甲板ではなく装甲の隙間を突く：** 青銅や鉄のブレストプレートを正面から叩き切ろうとするのはスタミナの無駄です。大腿動脈を狙って斜め下に突き刺すか、ヘルメットの顎下スリットを跳ね上げるように狙いましょう。
3. **まずは無料体験版を活用：** お使いのPCで物理演算の処理落ちが起きないか不安な場合は、Steamストアで配信されている無料デモ版を試してください。購入前に動作パフォーマンスやモーション作成の手触りを確認できます。
4. **敗因はリプレイで分析する：** 一瞬で倒されてしまったときは、タイムラインリプレイを活用しましょう。フリーカメラで傷口の進入軌道を観察すると、攻撃動作の踏み込み時に自ら相手の切っ先へ飛び込んでしまっているケースがよく見つかります。

解剖学的な知識と冷静な立ち回りを身につければ、**Gladio Mori Steam**版は単なるカオスな物理サンドボックスから、PC上で屈指の奥深さを誇るスキル志向の剣戟格闘ゲームへと進化します。

## よくある質問（FAQ）

### Gladio Mori Steam版の主な特徴は何ですか？
Steam版には、HPバーを廃したリアルな臓器部位ダメージシステムが採用されており、戦術的な部位切断、筋疲労、出血などが再現されています。さらに、キーフレーム単位のモーションエディター、mod.ioコミュニティ機能、自作スキンのインポート、34種類のベース武器、最大4人でのクロスプレイ対応などが含まれています。

### Steam版Gladio Moriは完全なクロスプレイに対応していますか？
はい。Steam（PC）版のプレイヤーは、PlayStation 5およびXbox Series X|S版のプレイヤーとシームレスなマッチメイキング、カスタムロビーの作成、オンライン対戦を楽しむことができます。

### Gladio MoriはSteam Deckで動作しますか？
はい。現在Steam Deckで「プレイ可能」評価を得ています。XboxおよびPlayStationコントローラー配列にネイティブ対応しており、グラフィック設定を中程度にしつつラグドール物理演算をオンにした状態でも安定したフレームレートを維持できます。

### Gladio Mori Steam版の自作モーション機能はどのように動作しますか？
ゲーム内のアニメーションスタジオに入り、構え、重心バランス、太刀筋の軌道を細かく設定します。作成したモーションはダイナミックなコンボとして保存でき、ダミー人形相手のテスト、オンライン対戦での使用、さらにはコミュニティギャラリーを通じた世界中への共有が可能です。
