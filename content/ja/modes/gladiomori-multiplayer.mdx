## マルチプレイヤーモードとマッチ形式の理解

決まったコンボメーターや静的な当たり判定に依存するアーケード格闘ゲームとは異なり、本作はリアルタイムの衝突検出によって動作します。選択可能なプレイオプションを把握することで、カジュアルな乱闘から厳格な競技デュエルまで、好みに応じたロビーを設定できるようになります。

ゲームは最大4人の戦士によるローカル画面分割対戦とオンラインマッチの両方に対応しています。プレイヤーはバトルロイヤル形式のフリーフォーオール、組織的な1対1のデュエル、あるいは総当たり戦の小競り合いに飛び込むことができます。

| マルチプレイヤーモード | 最大プレイヤー数 | 接続タイプ | 最適なプレイスタイル |
| :--- | :--- | :--- | :--- |
| **オンライン・フリーフォーオール** | 4人 | オンラインマッチメイキング / プライベート | 混沌とした大乱闘、パーティープレイ |
| **オンラインデュエル (1v1)** | 2人 | オンラインP2P / 専用ロビー | 本格的な競技対戦、ムーブセットの検証 |
| **ローカル画面共有** | 4人 | カウチコープ / 1台のマシン | 低遅延でのローカル大会 |
| **クロスプレイ・カスタム** | 4人 | クロスネットワーク・ルームコード | 異なるプラットフォームのフレンド同士 |

**Gladio Mori マルチプレイヤー**でセッションを主催する場合、ホストはアリーナ設定、武器制限、利用可能な装備セットを細かくカスタマイズできます。競技性を重視するコミュニティトーナメントでは、超重量のフルプレートアーマーを禁止したり、武器カテゴリを規定の長さに統一したりすることが一般的です。

### クロスプレイマッチへの参加およびホスト方法

1. ゲームを起動し、メイン画面から**Multiplayer**（マルチプレイヤー）メニューに進みます。
2. ロビーを作成するには**Host Arena**（アリーナをホスト）を、既存のセッションに接続するには**Join Arena**（アリーナに参加）を選択します。
3. ホストする場合は、ロビーを「Public」（公開）に設定するか、フレンド向けのユニークなクロスプレイルームコードを生成します。
4. 他のプラットフォームのフレンドに参加する場合は、直接接続プロンプトに相手のルームコードを入力します。
5. 準備完了（Ready）をクリックする前に、事前に構築したキャラクタースキン、装備武器、カスタムムーブセットを選択します。

異なるコンソールのエコシステムを跨いで4人対戦をホストする際に接続が切断される場合は、自宅のルーターでUPnPが有効になっていることを確認することがコミュニティから推奨されています。

## 戦闘メカニクス：内臓ダメージと出血システム

画面のどこを探しても、緑色の体力バーやシールドメーターは見当たりません。戦闘の結果は、すべてシミュレートされた外傷によって決まります。あらゆる一撃において、武器の速度、刃の角度（刃筋）、そして命中したポイントが計算されます。

**Gladio Mori マルチプレイヤー**で安定して勝利を収めるには、単にダメージを交換するのではなく、人体の解剖学的構造を狙い撃ちする必要があります。

| 解剖学的な標的部位 | 負傷の重症度 | 対戦相手への戦術的影響 |
| :--- | :--- | :--- |
| **主要筋肉群** | 中程度 | 武器の振りの速度や四肢の運動量を大幅に低下させる |
| **動脈 (首 / 太もも)** | 重度 (出血) | 急速な失血を引き起こし、数秒以内に対象を行動不能に追い込む |
| **重要臓器 (心臓 / 肺)** | 致死 | 即座の無力化、または即死をもたらす |
| **関節および四肢** | 切断 | 手首を切断されると武器を落とし、脚を切断されると移動不能になる |

四肢の切断がリアルタイムに機能するため、敵の利き腕の前腕を切り裂けば、一瞬で武器を奪い取ることができます。打ち合いの中で利き手を失った場合、剣闘士は生き残るために逆手の武器、キック、あるいは素手の殴り合いに頼らざるを得なくなります。

## 武器クラスとロードアウト戦略

34種類のベース武器と17種類の防具パーツが存在するため、マルチプレイヤーで生き残るにはロードアウトのバランスが極めて重要です。防具はそれが物理的に覆っている肉体のみを保護するため、脇の下、内もも、首元などに致命的な隙間が露出します。

| 武器カテゴリー | 一般的な射程 | 装甲貫通力 | 理想的なプレイスタイル |
| :--- | :--- | :--- | :--- |
| **短柄刃物 (グラディウス、短剣)** | 近距離 | 低〜中 | 素早いインファイトのフットワーク、動脈狙撃 |
| **長柄武器 (槍、ハルバード)** | 極長 | 高 (刺突) | 間合いの管理、安全圏からの刺突攻撃 |
| **両手用大刀 (関刀など)** | 長距離 | 高 (斬撃) | 広い範囲制圧、四肢の切断 |
| **打撃武器 (金棒、メイス)** | 中距離 | 極高 (打撃) | 骨折、重装プレートの上からの怯み誘発 |

### 防具の重量と俊敏性のトレードオフ

* **フルプレートアーマー:** 浅い斬撃をほぼ完全に無力化し、相手に目のスリットや股間の隙間を狙うことを強要します。ただし、重量が増加するためキャラクターの旋回速度が低下します。
* **軽レザー＆篭手:** 刺突に対する防御力はわずかですが、移動速度を最大限に維持できるため、熟練のデュエリストは敵の武器の当たり判定のすぐ外側をステップでかわし続けることが可能です。
* **無装甲デュエリスト:** 素早い踏み込みと瞬間的な離脱フレームに依存する、上級者が好むハイリスク・ハイリターンの戦略です。

## 競技PvP向けムーブセットの構築

本作を決定づける最大の特徴は、コマ送りで作成できるモーションアニメーションエディターです。プレイヤーは用意された連続攻撃に縛られることなく、関節を物理的に動かし、キーフレームを調整し、運動量曲線を設定して独自の攻撃を作り出すことができます。

**Gladio Mori マルチプレイヤー**用の技を準備する際、派手な大技はシンプルで素早い刺突によって容易に対処されてしまいがちです。対戦コミュニティの経験則では、不規則なアクロバットよりも実用的なムーブセットの方が遥かに優れた戦果を挙げることが証明されています。

| カスタム技のフェーズ | 目的 | マルチプレイヤー向け調整のコツ |
| :--- | :--- | :--- |
| **予備動作 (予備フレーム)** | 武器の慣性を溜める | 攻撃を読まれないよう、可能な限りフレームを短くする |
| **インパクト (攻撃判定発生)** | 刃が標的に接触する | 刃の向きをスイングのベクトルと完全に平行に合わせる |
| **硬直 (戻り動作)** | ガードの構えに戻る | 相手のカウンター刺突を防ぐため、硬直フレームを最小化する |
| **フォロースルー** | 次の振りへと繋げる | 防御姿勢へとスムーズに移行させ、返り討ちの攻撃を受け止める |

### アニメーション設計のベストプラクティス

* **刃筋（エッジアライメント）の重視:** 剣の平たい面で鎧を叩いても、ごくわずかな打撃衝撃しか与えられません。攻撃判定が発生しているすべてのフレームにおいて、鋭利な刃先がスイングの軌道をリードするように設定してください。
* **フェイントの組み込み:** 後方へのステップや、上段から下段への急な刺突へとスムーズにキャンセルできる予備動作を作り込みましょう。
* **武器の物理法則の尊重:** ハルバードのような過度に重い武器には、リアルな予備動作が必要です。不自然に速く動かそうとすると物理的なブレが生じ、攻撃の命中精度が著しく低下します。

## 死闘の振り返り：リプレイ分析

激しい試合を終えた後は、内蔵されたリプレイ機能を使って接戦の瞬間を詳細に分析できます。タイムラインツールを使用すれば、フレーム単位で打撃を巻き戻し、カメラを自由な角度に回転させ、武器がなぜ相手に弾かれたのか、あるいは防具の隙間をすり抜けたのかを正確に検証できます。

**Gladio Mori マルチプレイヤー**の試合リプレイを研究することは、長すぎる硬直フレームやパリィ時の誤った武器角度など、カスタムアニメーションの技術的な欠陥を発見するための最短ルートです。

## よくある質問 (FAQ)

### Gladio Mori マルチプレイヤーはランダムマッチメイキングに対応していますか？
はい、Steam、PlayStation 5、Xbox Series X|Sを跨いだフレンド向けのプライベートルームコードに加え、公開ロビーの検索や、誰でも参加できるオープンルームのホストが可能です。

### Gladio Mori マルチプレイヤーでコミュニティ作成のムーブセットを使用できますか？
はい。ゲーム内のMODブラウザからユーザー作成のムーブセット、カスタムスキン、コミュニティアリーナMODをダウンロードし、ホストがMODアセットを許可していればマルチプレイヤーマッチで直接装備して使用できます。

### オンラインで不公平または壊れたカスタムアニメーションが使われるのをどう防いでいますか？
基礎となる物理エンジンが、武器の質量、バランス、運動量を厳格に計算しています。超重量の武器を不自然な高速で振り回すようなアニメーションを設定しても、物理シミュレーションによってスイングの威力が減衰し、攻撃が相手に弾かれたり、自身の体勢が崩れたりします。

### PC版で画面分割マルチプレイヤーを遊ぶことはできますか？
はい、複数のコントローラーを接続することで、最大4人によるローカル画面共有マルチプレイヤーに完全対応しています。
