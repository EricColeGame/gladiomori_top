## Gladio Moriにおけるローカルマルチプレイと画面分割の仕組み

*Gladio Mori*は、奥深いモジュール式の技エディターと、解剖学的にモデル化されたラグドール物理によって、従来の格闘ゲームとは一線を画しています。当たり判定は武器の実際の接触、刃の速度、骨への衝撃に依存するため、ローカルでの対戦は最も純粋な競技環境を提供します。ネットワークの揺らぎ（ジッター）、ロールバックの描画乱れ、クライアント間の同期ズレなどは一切発生しません。

ローカルマルチプレイモードでは、ビューポートが動的に分割されるかカメラのフレーミングが固定され、両プレイヤーが互いの構えと間合いを完全に把握できるようになります。ソファ対戦をセットアップする際は、ディスプレイと入力機器の構成をあらかじめ理解しておくことで、戦闘中の予期せぬ操作不能トラブルを防ぐことができます。

### ローカル対戦の概要

| 機能 | ローカル対戦（オフライン） | オンラインロビー |
| :--- | :--- | :--- |
| **入力遅延** | 1ミリ秒未満（ハードウェア直結） | 変動あり（ネットワークPing＋バッファ） |
| **ローカル同時プレイ人数** | 最大2名（標準的な1対1） | クライアントPCごとに1名 |
| **カスタム技セットのサポート** | 対応（ローカルのユーザーセーブから読み込み） | 対応（認証済み技セットの同期） |
| **ハードウェア負荷** | 中程度（2画面の視点を描画） | 低〜中程度（単一のビューポート） |
| **装備変更** | ロビーリセットまたはラウンドリセットが必要 | マッチ再起動ごとに処理 |

最新のバランス調整パッチ、開発ログ、検証済みクライアントビルドについては、[Gladio Mori Steamコミュニティハブ](https://steamcommunity.com/app/2689120)を確認し、ローカルクライアントを常に最新の状態に保ってください。

## Gladio Moriの画面分割 vs オンラインマルチプレイ：対応状況について

プレイヤーからよく寄せられる質問の1つに、「1台のPCでローカル2人プレイをしながら、一緒に公開マッチメイキングサーバーに参加できるか」というものがあります。公式フォーラムでのコミュニティの議論により、この点について明確な回答が出されています。

コミュニティの報告および開発者RedDuelist氏の公式発表によると、本作ではローカル環境とオンライン環境が完全に独立した別個のフレームワークとして扱われています。具体的には、オンラインのマッチメイキングロビー内で**gladiomori split screen**を実行することはできません。同期の整合性を維持するため、ローカルマルチプレイはオフライン専用となっています。

### モード比較表

| マルチプレイ機能 | 対応状況 | 開発者ノート／コミュニティの補足 |
| :--- | :--- | :--- |
| **純粋なローカル画面分割** | 完全対応 | コントローラーを接続するだけで1対1の対戦が可能 |
| **ローカル＋オンラインのハイブリッド** | 非対応 | 開発者のRedDuelist氏によりオンラインは1クライアント専用と確認済み |
| **Steam Remote Play Together** | 実用的な代替策 | オンラインのフレンドにローカル画面をストリーミング可能 |
| **試合中の武器変更** | 制限あり | 現在はマッチインスタンスの再起動が必要 |
| **共有画面での観戦** | 対応 | 対戦の合間に空いているゲームパッドを他の人に渡して交代可能 |

一部のプレイヤーからはローカルとオンラインの統合が要望されていますが、物理演算主導のエンジンはシミュレーションのティックレートに極めて高い要求を課します。離れた場所にいるフレンドと自宅に招かずに戦いたい場合は、Steamの「Remote Play Together」を利用してローカル画面を相手のディスプレイに直接ストリーミングするのが有効な解決策となります。

## ローカル画面分割対戦のステップ別セットアップ手順

1対1の対戦環境を整えるのにかかる時間はほんの数分ですが、事前に入力設定を正しく構成しておくことでデバイスの競合を防ぐことができます。以下の体系的な手順に従ってセッションを開始してください。

### 設定チェックリスト

1. **メインゲームパッドの接続**: ゲームクライアントを起動する前に、XInput互換のコントローラー（Xbox Series X/SやDualSenseなど）を2台接続します。
2. **Steam入力の設定**: Steamの「設定」を開き、「コントローラ」タブに移動して、ボタンの重複入力を防ぐために標準のデスクトップ設定が無効になっていることを確認します。
3. **ゲームの起動**: メインメニューに入り、ローカルのデュエル/対戦モードを選択します。
4. **プロファイルの割り当て**: Player 1とPlayer 2に、それぞれの入力プロファイルとカスタムアニメーションのロードアウトを割り当てます。
5. **解像度スケーリングの調整**: 画面分割時にハードウェアのパフォーマンスが60 FPSを下回る場合は、影のディテールやラグドールの持続時間を下げてください。

### 滑らかな画面分割プレイのための推奨システム構成

物理演算を多用する本作で2つの視点を同時にレンダリングすると、シングルプレイヤーモードよりもGPUおよびCPUのドローコールが増加します。激しい攻防の中でも安定した60+ FPSを維持するための推奨ハードウェアスペックは以下の通りです。

| ハードウェア構成 | ターゲット解像度 | 推奨GPU | 推奨CPU | 想定パフォーマンス |
| :--- | :--- | :--- | :--- | :--- |
| **最小リビング環境** | 1080p @ 60 FPS | GTX 1660 Super / RX 5600 XT | Ryzen 5 3600 / Core i5-10400 | 安定した60 FPS（影設定：低） |
| **最適Eスポーツ仕様** | 1440p @ 120 FPS | RTX 3070 / RX 6700 XT | Ryzen 7 5800X / Core i5-12600K | 120 FPS固定（ラグドール最大） |
| **4KリビングTV** | 4K (2160p) @ 60 FPS | RTX 4070 / RX 7800 XT | Ryzen 7 7800X3D / Core i7-13700K | 大画面でのシネマティックな60 FPS |

## ローカル対戦に向けたカスタム技セットの最適化

本作の最大の強みは、プレイヤー自らが斬撃、フェイント、刺突、パリィを作り出せるアニメーションエディターにあります。**gladiomori split screen**でプレイする際、最適化された技構成を用意しておくことで、自分のあらゆる動きを見ている相手に対する勝率が劇的に上がります。

画面分割の試合では、画面の境界越しに対戦相手が攻撃の発生フレームを目視で予測できます。画面を覗き見できることはローカル対戦の避けられない特性であるため、モーションが大きく見切られやすい大技ではなく、硬直が短くフレームデータで惑わせる技セットを設計する必要があります。

### ローカルプレイに必須の攻撃アーキタイプ

| 攻撃アーキタイプ | 最適な武器種 | 発生フレーム速度 | 硬直リスク | 戦略的用途 |
| :--- | :--- | :--- | :--- | :--- |
| **クイックスナップ刺突** | レイピア / ショートソード | 極めて高速 (10-15フレーム) | 低 | ガード中央の隙を突いた大振りの空振りへの差し返し |
| **オーバーヘッド振り下ろし** | ロングソード / クレイモア | 中程度 (25-35フレーム) | 高 | 下段ガードを崩し、ノックダウンを奪う |
| **下段薙ぎ払いフェイント** | サーベル（曲刀） | キャンセルが素早い | 中 | パリィを誘発させてから斬撃に切り替える |
| **ディフェンシブ・チェンバーパリィ** | 任意の盾/刀剣 | 即座に判定が発生 | 失敗時は致命的 | 高速で斬撃を連打する相手へのカウンター |

### ローカル対戦の戦略的ヒント

- **構えを惑わす**: 不規則にフットワークを変えましょう。相手はあなたの入力や姿勢を直接観察できるため、上段と下段のガードを細かく切り替えることで予測パリィを防げます。
- **装甲貫通を重視する**: ローカルルールで重装甲プレートが許可されている場合、打撃攻撃やバイザーのスリットを狙う鋭い刺突がクリーンな一撃必殺を生み出します。
- **スタミナ管理の徹底**: 大ダメージの振りを多用してスタミナ切れを起こすと無防備になり、冷静な対戦相手に格好の処刑チャンスを与えてしまいます。

## ローカル画面分割でよくある問題のトラブルシューティング

高性能なPCハードウェアであっても、画面分割インターフェース経由で2台のゲームパッドを使用すると、デバイスの競合やドライバーの不具合が発生することがあります。以下の診断表を活用して、プレイ中のトラブルを素早く解消してください。

### 症状と解決手順

| 症状 | 根本原因 | 即座に実行できる解決策 |
| :--- | :--- | :--- |
| **両方のゲームパッドがPlayer 1を操作してしまう** | XInput/DirectInput割り当ての重複 | Steamの「一般的なコントローラのサポート」を無効化し、「Xbox設定サポート」のみを有効にする。 |
| **フレームレートのばらつきや微小なカクつき** | 2画面視点のドローコールによるGPU負荷 | 動的な影解像度を下げ、NvidiaコントロールパネルまたはAMD Adrenalinでディスプレイのリフレッシュレートを固定する。 |
| **2人目のプレイヤーがカスタム技を選択できない** | ユーザーアニメーションフォルダの読み取り制限 | カスタムアニメーションファイルが、すべてのローカルプレイヤースロットからアクセス可能な共有ディレクトリに配置されていることを確認する。 |
| **対戦中に一方のコントローラーの接続が切れる** | USB省電力モードによるポートのスリープ | Windowsのデバイスマネージャー -> ユニバーサル シリアル バス コントローラー -> プロパティを開き、「電力の節約のために、コンピューターでこのデバイスの電源をオフにできるようにする」のチェックを外す。 |

これらの簡単な修正手順を実行することで、**gladiomori split screen**の対戦を快適かつ公平に、入力途切れのストレスなく楽しむことができます。

## よくある質問

### Gladio Moriの画面分割でオンラインの見知らぬ相手と対戦できますか？
いいえ。コミュニティの報告および開発者のコメントにある通り、ローカルゲームプレイは完全にオフライン専用です。画面分割の状態でオンラインのマッチメイキングサーバーに同時に参加することはできません。離れた場所にいるフレンドと一緒にプレイしたい場合は、Steam Remote Play Togetherを利用する必要があります。

### 1つの画面でGladio Moriを何人までプレイできますか？
現在、標準的なローカル対戦は1対1のデュエルに特化しています。2人のプレイヤーが武器の間合いとタイミングを完全に把握できるよう、画面が分割されるか適切なフレーミングに調整されます。

### Gladio Moriの画面分割でもカスタム技セットは正常に動作しますか？
はい。必要なファイルがホストPC内に保存されていれば、ラウンド開始前のキャラクター選択画面で、両プレイヤーがそれぞれのカスタム攻撃コンボや防御の構えを選択できます。

### Player 2のコントローラーが認識されないのはなぜですか？
これは多くの場合、Steam入力の競合が原因です。ゲームを起動する前に、両方のコントローラーの電源が入り、Windowsに認識されていることを確認してください。Player 2の入力がPlayer 1と重複してしまう場合は、Steamのコントローラー設定を確認し、仮想デバイスを1つのスロットに統合してしまうようなサードパーティ製マッピングソフトを無効にしてください。ネイティブのXInput対応ゲームパッドを使用して**gladiomori split screen**セッションを行えば、常に問題なく認識されます。
