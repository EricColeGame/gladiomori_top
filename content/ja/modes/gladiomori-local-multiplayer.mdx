## Gladio Mori ローカルマルチプレイヤーの仕組み

Plebeian Studioが開発した『Gladio Mori』は、従来の格闘ゲームの常識を覆す作品です。ヒットポイントを少しずつ削るのではなく、プレイヤーは高度なシミュレーションに基づく解剖学的ダメージシステムと向き合うことになります。本作は[Gladio Mori Steamストアページ](https://store.steampowered.com/app/2689120/Gladio_Mori/)にあるオンライン機能に加え、ネイティブの画面共有／画面分割をサポートしているため、オフライン対戦の設定は非常にスムーズです。

ローカルの画面共有デュエルでは、両プレイヤーが遮るもののない戦闘空間の視界を共有します。ダイナミックカメラがプレイヤー同士の距離を追跡し、間合いを詰めたり、踏み込んだり、後退したりする動きに合わせて自動でパンやズームを行います。

### 解剖学的ダメージ vs 従来の体力システム

ローカル対戦の緊張感が際立っているのは、的確な一撃が決まればその場で勝負が決まるためです。安全な攻撃を当て合って削り合う消耗戦は存在しません。刃のジオメトリがキャラクターのヒットボックスに接触した正確な位置に応じて、以下のようなダメージ判定が発生します。

*   **筋肉の損傷：** 攻撃速度が大幅に低下します。上腕二頭筋を攻撃されると、重量のある長柄武器をまともに振ることができなくなります。
*   **動脈出血：** 主要な動脈を傷つけられると、タイムリミットが始まります。負傷した剣闘士は、失血で倒れる前に攻め立てて勝負を決める必要があります。
*   **急所への直撃：** 心臓、脊椎、脳幹を貫通されると、即死判定となります。
*   **切断：** 手、前腕、脚をきれいに切り落とされることがあります。利き手を失うと即座に武器を落とし、脚を失うと無様に地面を這い回ることしかできなくなります。

## ローカル対戦のためのハードウェアおよびコントローラー設定

PCや対応コンソールで**Gladio Mori local multiplayer**を快適に動作させるには、デュエルを開始する前に入力プロファイルを正しくマッピングしておくことが不可欠です。ソロプレイであればキーボード＆マウスでも十分戦えますが、ローカル対戦では各プレイヤーが専用のゲームパッドを使用するのがベストです。

### コントローラー互換性マトリクス

| コントローラーの種類 | 接続方法 | プラグ＆プレイ対応 | 推奨プレイヤースロット |
| :--- | :--- | :--- | :--- |
| **Xbox ワイヤレス（Series / One）** | USB-C / Bluetooth / Xbox ワイヤレスアダプター | ネイティブ対応（XInput） | プレイヤー1〜4 |
| **PlayStation DualSense / DualShock 4** | USB-C / Bluetooth | Steam Input経由でネイティブ対応 | プレイヤー1〜4 |
| **DirectInput / レトロゲームパッド** | USB / 2.4GHzドングル | Steamのコントローラー再マッピングが必要 | カジュアル / 予備用 |
| **キーボード＆マウス** | USB直接接続 | ネイティブ対応（プライマリプロファイル） | プレイヤー1のみ |

### ローカルロビー設定のステップ・バイ・ステップ

1. **コントローラーの接続：** ゲームを起動する前にすべてのゲームパッドを接続し、ゲームエンジンが入力IDを順番に正しく割り当てられるようにします。
2. **Steam Inputの設定：** PC上でDualSenseとXboxコントローラーを混在させる場合は、Steamの設定内で「一般的なゲームパッド設定サポート」を有効にし、予期しない誤入力を防止します。
3. **ローカル対戦へ移動：** メインメニューから、オンラインマッチメイキングロビーではなく、ローカルPvPデュエルモードを選択します。
4. **操作レイアウトの選択：** プレイヤー1とプレイヤー2を割り当てます。どちらかのプレイヤーがキーボード操作を希望する場合は、プレイヤー2を最初に接続されたゲームパッドに割り当ててください。
5. **ラウンドモディファイアの設定：** 試合時間、アリーナの境界、コミュニティ製カスタム技の持ち込み可否を調整します。

## 画面共有対戦のための上級戦闘戦術

隣に相手が座っているローカル対戦で勝利するには、顔の見えないオンラインマッチとは異なる特有の駆け引きが求められます。相手がわずか数十センチ隣にいる状況では、心理戦と「刃の角度（エッジアライメント）」が最大の武器となります。

```
戦術の流れ：
間合いの支配（槍／長柄武器） 
   └── 相手の大振りを誘い出す 
         └── 攻撃の軌道の内側へ踏み込む 
               └── 無防備な動脈／関節を精密攻撃
```

### 1. 刃筋（エッジアライメント）の習得
刃物系の武器は、スイングの軌道と刃の向きが正確に一致していなければ綺麗な切断になりません。平打ち（刃の側面）で当ててしまうと、衣服に当たって無害に弾かれるか、相手勢を崩すだけで肉体を切り裂くことはできません。攻撃時には腰の回転トルクをしっかり連動させ、刃の先端が切り込みの軌道をリードするように意識してください。

### 2. 武器を持つ腕を狙う
相手が威力重視の上段両手叩きつけを多用してくる場合は、素早い下段突きで相手の右手首や前腕を狙いましょう。前腕の筋肉を破裂させれば重い武器を持ち上げられなくなり、手首を切断すればその時点で相手の主武装を完全に無力化できます。

### 3. 共有カメラの死角を突く
画面共有の対戦では、アリーナの端へ後退することでカメラのアングルが大きく変化します。急な横移動で相手の視線軸をズラし、カメラのパースペクティブの死角を利用して低い姿勢からの刺突を隠すテクニックが極めて有効です。

### 4. 内蔵リプレイ機能の活用
衝撃的な首飛ばしが決まった際や、両者が同時に失血死してダブルノックアウトになった場合は、ゲーム内リプレイビューアーを活用しましょう。フリーカメラでタイムラインをコマ送り再生することで、どちらの刃が何ミリ秒先に命中していたのかを正確に検証・鑑賞できます。

## よくある質問（FAQ）

### Gladio Moriのローカルマルチプレイヤーは、キーボード1台とコントローラー1台でプレイできますか？
はい、可能です。1人のプレイヤーがキーボード＆マウスのプロファイルを使用し、もう1人のプレイヤーが接続されたゲームパッドを操作して対戦できます。ただし、操作の公平性やエルゴノミクスを考慮すると、2台のゲームパッドを用意するのが最も理想的です。

### ローカルマルチプレイヤーでは同時に何人まで対戦できますか？
ローカルの画面共有／分割対戦では、コントローラーの接続数に応じて、1対1の真剣勝負から複数人による乱闘まで対応しています。オンラインマッチメイキングに進む前に、オフラインで最大4人のプレイヤーが同じアリーナで対戦可能です。

### コミュニティ製のスキンモッドや自作モーションはオフラインのローカル対戦でも機能しますか？
はい。ローカルプロファイルに保存されているスキンのテンプレート、ペイントされた剣闘士モデル、ダウンロードした技セットは、両プレイヤーがローカルのキャラクター選択画面からプリセットを選択することで、オフラインの共有画面マッチでも問題なく使用できます。

### Gladio Moriの戦闘は、他の一般的な格闘ゲームと何が違うのですか？
一般的な体力ゲージを削り切るシステムとは異なり、**gladiomori local multiplayer**は物理演算に基づくリアルな解剖学的ダメージのみで勝敗が決まります。骨折、動脈切断、四肢の欠損、あるいは急所となる内臓への精密な一撃を叩き込むことによってラウンドを制覇します。
