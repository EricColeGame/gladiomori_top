## 物理演算駆動型戦闘システムの理解

キーフレーム編集に飛び込む前に、ゲームがプレイヤーの入力をどのように物理的な致死性へと変換しているかを把握する必要があります。すべての振り、パリィ、回避は、動的コリジョン（衝突判定）、骨格のてこ作用、武器の重量によって制御されています。

いわゆる無敵フレーム（無敵時間）に依存するのではなく、本作の防御は完全に「物理的な遮蔽」に依存しています。攻撃後の硬直中にデーンアックスやポラックスの刃が露出した喉元に接触すれば、即座に死亡します。そのため、効果的なムーブセットを構築するには、攻撃的なリーチと防御面での隙のバランスを取ることが不可欠です。

| 戦闘コンポーネント | コア機能 | 技設計への影響 |
| :--- | :--- | :--- |
| **臓器ターゲティング** | 致命的な外傷（心臓、脳、肺、動脈）を判定 | 武器の刃筋を無防備な急所領域へ正確に合わせる必要がある。 |
| **スケルタルリギング** | 骨格の配置、関節の回転、バランスを追跡 | スタンスを広げるとバランスは向上するが、方向転換や復帰が遅くなる。 |

## ゲーム内ムーブエディター：ステップバイステップ解説

ムーブエディターは、キャラクターカスタマイズの核心です。ここでは、線形キーフレームタイムライン上でバーチャルなラグドールマネキンを操作し、関節の回転、四肢の伸縮、重量配分を細かく調整します。

```
キーフレームタイムラインの流れ：
[予備動作フェーズ] -> [加速フェーズ] -> [攻撃判定発生 / リリース] -> [フォロースルー] -> [構え復帰]
```

カスタム**gladiomori moves**を作成する際の第一の目的は、予備動作と硬直時間を最小限に抑えつつ、攻撃判定発生フェーズの速度を最大化することです。

| フェーズ | 推奨持続時間（Tick/フレーム） | 主な焦点 | よくある失敗 |
| :--- | :--- | :--- | :--- |
| **予備動作（Windup）** | 4 – 8フレーム | 重心の移動、てこの原理の構築 | 攻撃方向を早い段階で悟られる |
| **加速（Acceleration）** | 3 – 5フレーム | 股関節と体幹の回転による推進力 | 体幹の連動なしに四肢だけで動かしてしまう |
| **判定発生（Active Hitbox）** | 2 – 4フレーム | 正確な刃筋調整、急所狙撃 | 武器の切っ先が手首より遅れて追従する |
| **フォロースルー** | 4 – 6フレーム | 運動エネルギーの吸収、バランス回復 | 目標ラインを越えて過剰に回転しすぎる |
| **構え復帰（Reset）** | 5 – 10フレーム | 防御ガードへのスムーズな移行 | 頭部や肋骨が無防備なまま放置される |

信頼性の高い打撃を生み出すには、まず戦士の両足と腰のポージングから始めましょう。回転力は下半身から生まれます。両手持ち武器を振る際に足元が静止したままだと、打撃の衝撃力が不足します。振り下ろし攻撃の際は上半身をわずかに前傾させ、体重を下方へ乗せることで打撃に乗る威力を高めましょう。

コミュニティの報告でも、短く再現性の高いトランジションアニメーションの重要性が強調されています。攻撃の終了ポーズが無理な姿勢や伸び切った状態になっていると、エンジンによって長時間の復帰硬直が発生し、敵の反撃に対して無力になってしまいます。

## 臓器ダメージメカニクスとヒットボックスの優先順位

従来のヘルスバーで勝敗が決まるタイトルとは異なり、闘技場での勝利は構造的・解剖学的な破壊にかかっています。体内構造を理解することは、**gladiomori moves**の設計に直結します。

敵の上腕二頭筋や前腕を切り裂けば筋肉組織が破壊され、ガードを構えたり重い両手武器を保持したりすることができなくなります。頸動脈や頸静脈を刺突すれば急速な失血を引き起こし、数秒で意識不明に陥ります。頭蓋骨への直接的な強打は、即座の運動機能停止をもたらします。

| 標的部位 | 主な解剖学的影響 | 最適な武器タイプ | 戦略的価値 |
| :--- | :--- | :--- | :--- |
| **頭部 / 首** | 即時ノックアウト、急速失血死、切断 | 両手斧、大型ポールウェポン、刺突剣 | リスクは高いが、即座に決着をつける致死性 |
| **胸部 / 心臓** | 重篤なスタミナ喪失、肺虚脱による迅速な死 | 鋭利な刺突剣、細身の槍先 | 大振りな攻撃に対するカウンターとして最適 |
| **前腕 / 手** | 武装解除、パリィやガード維持の不能化 | 敏捷な片手アーミングソード、ダガー | リスクを最小限に抑えた安全な牽制ダメージ |
| **大腿動脈 / 膝** | 機動力の喪失、回避や前進の不能化 | 低位置の薙ぎ払い、低角度のハルバード/斧 | アグレッシブな突進型プレイスタイルを無力化 |

**gladiomori moves**を組む際は、武器の切っ先を致死確率の高いゾーンに向けるように設定してください。垂直の振り下ろしは正中線をまっすぐ通るように軌道を描かせ、頭蓋骨を砕くか、鎖骨を断ち割って心腔へと達するようにします。一方、水平の横薙ぎは、首の高さと完全に平行になるよう調整するのが最も効果的です。

## 高度な戦闘戦術：フェイント、フットワーク、スタミナ

優れたアニメーションを作り上げることは戦いの半分に過ぎません。実戦の動的な戦いの中で、カスタム**gladiomori moves**をどのように繰り出すかによって、伝説の剣闘士となるか無言の屍となるかが分かれます。

### キネティック・ピボット（運動軸調整）の活用

打撃の位置調整を、デフォルトの移動キーだけに頼ってはいけません。攻撃アニメーションが加速フェーズに入ったら、マウス（カメラ）を手動で旋回させ、武器の先端を目標へと巻き込むように振り抜きます。熟練プレイヤーの間で「アクセラレーション（加速）」や「ドラッグ（引き摺り）」と呼ばれるこのテクニックを使えば、相手のパリィ判定をすり抜けたり、無防備な四肢へ想定よりも早く当てたりすることが可能になります。

### バランスの取れた技構成（デッキ）の構築

装備する技構成を、低速で重い振り下ろし攻撃だけで固めてはいけません。バランスの取れたセットアップには、主に3つの戦術的役割が必要です。

1. **インターラプター（迎撃技）：** 相手の攻撃の予備動作フレームを潰すために設計された、電光石火の直線的なジャブ（通常は直線的な突き）。
2. **ゾーンクリアラー（範囲制圧技）：** 広い弧を描く水平斬りで、相手の横移動やローリングを狩るための技。
3. **アーマーブレイカー（装甲破壊技）：** 相手の構えを強引にこじ開け、スタミナを削り、頭蓋骨に強打を与えるための、前方に体重を乗せた重打撃。

```
戦闘時の判断フロー：
敵が前方に突進してきた場合 -> インターラプター（突き）を実行 -> 敵を怯ませる
敵が高い位置でガードを固めている場合 -> ロー・スイーパーを実行 -> 大腿動脈/腱を切断
敵の重攻撃が空振りした場合 -> アーマーブレイカーを実行 -> 露出した頭蓋骨を粉砕
```

### スタミナマネジメント

キーフレームの変更は、すべて物理的な結果を伴います。重い武器の速度や軌道を大きくすると、スタミナ消費量が跳ね上がります。攻防の中でスタミナメーターが完全に枯渇すると、戦士の太刀筋は目に見えて鈍くなり、無防備なガードを晒して単純な反撃の餌食になります。アニメーションシーケンスは無駄を削ぎ落とし、過剰な装飾を排除して、実用的かつ意図的な設計を心がけてください。

### 作成したカスタムgladiomori movesが戦闘中に遅く、弱く感じるのはなぜですか？
打撃が鈍い原因の多くは、ムーブエディター内でのキネティックチェーン（運動連鎖）の設計不足にあります。腰や胸を回転させず腕だけを動かすアニメーションになっていると、武器に十分な速度が乗りません。予備動作フレームに体幹の回転と前方への体重移動を組み込み、打撃の威力を最大化させてください。

### gladiomori movesの作成を学ぶ初心者にとって、最適な武器は何ですか？

### 作成するカスタム技によってスタミナ消費量は変化しますか？
