## Frequently Asked Questions

### What button do you press to jump in Gladio Mori?
There is no default button to jump in the base version of the game. If you see players jumping freely, they are either using third-party physics mods, custom scripts bound to a key like the Spacebar, or specifically keyframed animations created in the move editor.

### Can you get banned for using jump mods in multiplayer?
Most casual custom lobbies allow modded gameplay as long as both clients share the same files, but using movement scripts that alter physics parameters in standard matchmaking can cause server desynchronization or conflicts with game stability.

### Why did the developers design Gladio Mori without a jump mechanic?
The developers prioritized historical European martial arts (HEMA) realism. Jumping during an unarmored or armored sword duel compromises balance, leaves the fighter unable to parry, and exposes vital organs to counter-thrusts.

### Is learning Gladio Mori how to jump useful for beginner players?
No. Beginners should focus on spacing, weapon grip distance, balance recovery, and mastering the combat editor. Trying to leap over attacks usually results in being stabbed mid-air due to predictable trajectories.
